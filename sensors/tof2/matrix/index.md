# 測距者 2 路 (TOF2) × MATRIX Mini R4

測距者 2 路 (TOF2)用在 MATRIX Mini R4：先確認要買哪個版本、怎麼接，再選你用的軟體，之後整頁都只講那個軟體。

<figure class="guide-hero"><img src="/images/illust/host-matrix.webp" alt="MATRIX Mini R4"></figure>

## 要買哪個版本

買 **MATRIX 版**，用 MATRIX 原廠 4 pin 感應器線接 Mini R4 的 I2C1 或 I2C2（位址 `0x22`），積木裡選對應的孔。
