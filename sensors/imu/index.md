## 🚀 產品概述

機器人走直線、轉精準角度，全靠陀螺儀。但一般陀螺儀有兩個老問題：**必須水平安裝**，以及**時間一久航向會慢慢飄移**。

MBC 陀螺儀 IMU 結合 6 軸慣性感測（陀螺儀＋加速度計）與磁力計，內建三種航向演算法：

- **立體補償航向（Gyro3D）**：自動偵測安裝方向，**任意角度組裝**都能算出正確航向，最推薦優先使用。
- **磁力計融合航向（GyroCompass）**：用磁力計校正陀螺儀的累積誤差，**長距離行駛也不飄移**。
- **單軸陀螺儀＋磁力計航向**：傳統單軸航向，以及只靠磁力計算出的航向（相對值：開機或歸零時為 0，不是指北的方位角）。

## 🎯 核心優勢

- 🧭 **任意角度安裝**：自動擷取安裝軸，直放、側放、倒放都能正確計算航向
- 📉 **長距離不飄移**：磁力計融合航向持續校正陀螺儀誤差
- 🧱 **EV3 直接當原廠陀螺儀用**：在 EV3 官方軟體用原本的陀螺儀積木即可讀取
- 🔘 **按鍵校準**：加速度計與磁力計各有校準按鍵，校準結果存在機身
- 📊 **完整九軸資料**：角速度、加速度、磁力三軸原始數據都能讀取

## ∿ 通用 I2C 暫存器（位址 `0x6A`）

共通規則與 Arduino 函式請看 [MBC 通用 I2C 協議](/i2c-protocol.md)。所有軸向皆為感應器本體座標，航向單位 1°，開機或歸零時 = 0。

- **航向方向：** 從上往下看**右轉（順時針）數值變大**，會一直累加（轉兩圈 = 720），不會繞回 0~359；要 0~359 請自己換算 `((h % 360) + 360) % 360`。超過 ±32767 會繞回。三種航向都是相對值（不是指北的羅盤角度）。
- **開機：** 放著不動約 0.5 秒，`0x32` bit0（就緒）才會變 1；開機時會自動歸零。

> [!TIP]
> **不會寫程式也能用：** 看 [🧪 Arduino 範例](/sensors/imu/arduino-examples.md)，每個範例都能直接複製上傳，每一行都有中文說明。

| 暫存器 | 方向 | 長度 | 內容 |
| :---: | :---: | :---: | :--- |
| `0x10` | W | 1 | `0x01` = 航向歸零（寫入後等 30 ms 再讀） |
| `0x11` | R | 6 | 航向合併包（= `0x12` ~ `0x14`） |
| `0x12` | R | 2 | 陀螺單軸航向 int16，度 |
| `0x13` | R | 2 | 陀螺立體補償航向 (Gyro3D) int16，度 |
| `0x14` | R | 2 | 陀螺＋磁力計融合航向 int16，度（相對值，歸零時 = 0） |
| `0x20` | W | 1 | `0x01` / `0x02` 加速度計校準開始／結束；`0x03` / `0x04` 磁力計校準開始／結束 |
| `0x21` | R | 18 | 九軸合併包（= `0x22` ~ `0x24`） |
| `0x22` | R | 6 | 角速度 X / Y / Z int16，單位 0.1 °/s（右手定則：從該軸正端看逆時針為正，所以 Z 朝上右轉時為負，跟航向正負相反） |
| `0x23` | R | 6 | 加速度 X / Y / Z int16，單位 mg |
| `0x24` | R | 6 | 磁力 X / Y / Z int16，單位 mG（已套用校準） |
| `0x32` | R | 1 | bit0 就緒、bit1 靜止、bit2 已擷取安裝軸、bit3 安裝過歪、bit4 加速度計校準中、bit5 磁力計校準中、bit6 融合已初始化、bit7 磁力自動校準收斂 |
| `0x34` | R | 1 | 磁力計信任度 `0` ~ `255` |
| `0x35` | R | 1 | 磁場干擾程度（單位 0.01°／次更新，上限 255） |
| `0x36` | R | 1 | 朝上的面（0 = +X、1 = +Y、2 = +Z、3 = -X、4 = -Y、5 = -Z） |

```cpp
// 讀三種航向
uint8_t d[6];
if (iicRead(0x6A, 0x11, d, 6)) {
  int16_t gyro1D = (int16_t)(((uint16_t)d[0] << 8) | d[1]);
  int16_t gyro3D = (int16_t)(((uint16_t)d[2] << 8) | d[3]);   // 建議使用：右轉變大
  int16_t fused  = (int16_t)(((uint16_t)d[4] << 8) | d[5]);   // 融合航向（相對值，不是指北）
}
iicWrite(0x6A, 0x10, 0x01);                          // 航向歸零
delay(30);                                           // 等歸零生效再讀
```
