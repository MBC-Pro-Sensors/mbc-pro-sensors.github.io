# mBlock 5 讀值教學

> [!WARNING]
> **v1 尚未上機驗證**：數值排法已定案並通過電腦端測試，實機數值（fps、循線門檻）上機後可能調整；mBlock 版只在電腦上測過傳輸（每個值編號的回應、E0／E1、逾時），**還沒接 mBot 實測**。

神攝手通用版 v1 的 **mBlock 版韌體**讓 mBot、mBot Ranger、Orion、MegaPi 用 mBlock 5 的積木讀相機：MBC 感應器擴展 **v2.1.0** 多了一個「神攝手通用版」分類（22 顆積木）。值表跟 [Arduino I2C 版](/sensors/unicam/arduino/index.md) 完全相同，只是改走 RJ25 串口；積木會自己先問相機目前的模式，再讀對的值。

## 接線

相機要燒 **mBlock 版韌體**（跟 SPIKE／EV3／MATRIX／I2C 版是不同的 .bin，請跟我們索取已燒好的相機）。

| 主機 | 怎麼接 | 能用的連接埠 |
| :--- | :--- | :--- |
| mBot（mCore） | 相機 → **mBot 插座片** → RJ25 連接埠 | 1～4 |
| mBot Ranger（Auriga） | 同上 | 6～10（1～4 是紅色馬達埠、5 是硬體序列埠） |
| Orion | 同上 | 3、4、6（1、2 約 12 V 馬達埠；7、8 送腳只能類比輸入） |
| Ultimate 2.0（MegaPi） | RJ25 擴充板 | 6～8 |
| MegaPi Pro | RJ25 擴充板 | 7～10 |
| 一般 Arduino 板（UNO、Mega…） | 相機 TX（IO1）→ 板子 RX、相機 RX（IO3）← 板子 TX、5V、GND（見下面「不用 mBlock」） | UNO 用軟體串口、Mega 用 Serial1 |

- 串口 **38400 bps、8N1**，相機 RX＝IO3、TX＝IO1，跟主機**交叉接**（插座片已經接好，S1＝主機送、S2＝主機收）。
- mBot2（CyberPi）沒有 RJ25 埠，不支援。

> [!CAUTION]
> **不經插座片、直接接 5 V 的 Arduino 板時**：UNO／Mega 的 TX 是 5 V，ESP32 的腳位只耐 3.3 V，板子 TX → 相機 RX 中間要串分壓（例 1 kΩ＋2 kΩ）；相機 TX → 板子 RX 可以直接接。

## 安裝擴展

1. **擴展新版開發中**：MBC 感應器擴展 v2.1.0 還在開發，**正式上架前可先下載匯入檔試用（尚未上機驗證）**；上架後會在 mBlock 5「擴展中心」搜尋「MBC」就能加入，到時這一頁會更新。
2. **用匯入檔試用**：下載 [MBC_Pro_Sensors_mBlock5_v2.1.0_import.mext](/downloads/MBC_Pro_Sensors_mBlock5_v2.1.0_import.mext) → 到 [ext.mblock.cc](https://ext.mblock.cc) 登入自己的 Makeblock 帳號 → 我的擴展 → 匯入資料 → 上傳（約 2 分鐘，等到出現匯入成功再離開頁面）→ 按「下載」取得可以拖進 mBlock 的 `.mext`。
3. 打開 **mBlock 5 電腦版**，左下「設備」加入你的主板（例如 mBot），把 `.mext` **拖進 mBlock 視窗**，積木區會多出「神攝手通用版」分類（還有循行者、測距者等其他 MBC 分類）。
4. 右下「模式開關」切到 **上傳**：這個擴展只支援上傳模式（程式燒進主板執行）。

擴展 v2.1.0 的其他分類（循行者、測距者、掌控者、IMU、神攝手學校版／WRO 版）跟 v2.0.0 完全一樣，見 [MakeBlock 積木擴展](/makeblock.md)。

## 先切相機模式

同一個值編號在不同相機模式代表不同東西（`0x10` 在顏色追蹤是第 1 色 x、在循線是近處偏移），所以程式一開始先放「設定模式」，或在相機選單（MODE）切好。讀值積木每次會先讀 **模式編號（值 `0x01`）**（100 ms 內用上次讀到的），模式不對就傳回 **−32768**。

| 「設定模式」選項 | 模式編號（0x01） | 送出的命令 |
| :--- | :---: | :--- |
| 顏色追蹤 ① 最多色 | 11 | `E0 [1, 1]` |
| 顏色追蹤 ② 多色 | 12 | `E0 [1, 2]` |
| 顏色追蹤 ③ 標準 | 13 | `E0 [1, 3]` |
| 顏色追蹤 ④ 精細 | 14 | `E0 [1, 4]` |
| 座標取色 ① 色相 | 21 | `E0 [2, 1]` |
| 座標取色 ② 色相＋飽和 | 22 | `E0 [2, 2]` |
| 座標取色 ③ 色相＋飽和＋明度 | 23 | `E0 [2, 3]` |
| 照順序給色號 | 30 | `E0 [3, 0]` |
| 循線 ① 黑線 | 41 | `E0 [4, 1]` |
| 循線 ② 白線 | 42 | `E0 [4, 2]` |
| 循線 ③ 色線 | 43 | `E0 [4, 3]` |

目標顏色**只能在相機上教**（停在目標 1～16 按 OK）；程式改不了顏色。座標取色的取樣點位置可以用「設定取樣點」積木改（存進相機）。

## 積木一覽

連接埠選感應器實際插的孔。**第 c 色**＝相機上的目標 c（1 起算，跟相機螢幕上的編號一樣）；**k**＝這個子選項每色（每點）佔幾個值：顏色追蹤 ① 2、② 3、③ 4、④ 6；座標取色 ① 1、② 2、③ 3。

| 神攝手通用版 連接埠［1］ 看到線？ | 是／否 | 循線（41~43） | `0x15` | 有線旗標（近 1＋中 2＋遠 4）不是 0 |
| 神攝手通用版 連接埠［1］ 第 （數字） 個值 | 數字 | 全部 | `0x10~0x7F` | 規格值表的「值 N」＝編號 0x10＋N−1（N 1~112），可以放變數 |
| 神攝手通用版 連接埠［1］ 讀值編號 （數字） | 數字 | 全部 | `0x00~0xFF` | 直接讀一個值編號（十進位，例 16 = 0x10、240 = 0xF0） |
| 神攝手通用版 連接埠［1］ 感應器正常？ | 是／否 | 全部 | `0xF0` | 有回應而且裝置 ID 是神攝手通用版（F0 = 0x034C） |

- 傳回 **−32768**：讀不到（逾時、檢查碼錯、沒接）或這個模式／子選項沒有這個值（例：① 最多色沒有寬、高）。布林積木這時是「否」。
- 每色裡的位置：① X Y；② X Y 數量；③ X Y 面積 數量；④ X Y 寬 高 數量 面積（跟 [讀值參考：I2C](/sensors/unicam/reference.md#host-i2c) 的順序一樣）。
- 參數超出範圍會夾到上下限（第 0 色當第 1 色、第 99 色當第 16 色）。

## 通訊方式

- 讀值：主機送 **1 byte［編號］** → 相機回 **［值低］［值高］［編號 ^ 值低 ^ 值高］**（int16 小端）；沒有的編號回 `[00][80][編號^80]`（−32768）。函式庫等 10 ms。
- 寫入：**E0［相機模式, 子選項］**、**E1［第幾點, X, Y］**；參數收齊才回 ACK `[00][00][編號]` 再執行，20 ms 沒收齊就丟棄。EF 回 ACK 後重開機；沒有 F8（換位址只對 I2C 有意義）。
- 整包 **FD** 會回 235 byte（116 個值），超過 Arduino UNO 串口緩衝 64 byte，所以擴展**不提供「更新全部數值」**，每顆積木只問自己要的那一個值（一個值約 1 ms）。
- 共用值：F0 裝置 ID＝`0x034C`（「感應器正常？」就是看這個）、F1 協議版 2、F2 韌體版 100、F3 狀態旗標（bit0 就緒＝開機完成且鏡頭正常、bit1 目前模式有找到東西）。

```cpp
// 神攝手通用版 × mBot：最小讀值程式（跟上面的積木做一樣的事，Arduino IDE 版）
// 需要 Makeblock 函式庫＋MBC_Sensors v2.1.0（擴展 .mext 解壓後 src/ 的四個檔放進 文件/Arduino/libraries/MBC_Sensors/）
#include <MeMCore.h>
#include <SoftwareSerial.h>
#include <MBC_Sensors.h>

MBCPort cam(1);                 // 相機接 mBot 連接埠 1
MeRGBLed rgbled(7, 2);

void setup() {
  cam.begin();
  delay(2000);                  // 等相機開機
  ucSetMode(cam, 13);           // 顏色追蹤 ③ 標準（E0 [1, 3]）
  while (1) {
    if (ucFound(cam, 1)) {      // 第 1 色有找到？
      int x = ucBlob(cam, 1, 0);          // 第 1 色 x（0~159）
      rgbled.setColor(0, 0, x, 0);        // 越右邊越亮的綠燈
    } else {
      rgbled.setColor(0, 40, 0, 0);       // 沒找到：暗紅燈
    }
    rgbled.show();
  }
}

void loop() {}
```

## 不用 mBlock：一般 Arduino 板

擴展裡的 `MBC_Sensors` 函式庫也能直接在 Arduino IDE 用：把 `.mext` 解壓後 `src/` 的四個檔（MBC_Sensors.h/.cpp、mbc_proto.h、mbc_ids.h）放進 `文件/Arduino/libraries/MBC_Sensors/`，`MBCPort` 用 `begin(串口)` 接任何串口。函式名稱跟積木一一對應（`ucSetMode`、`ucBlob`、`ucFound`、`ucSpot`、`ucOrderHue`、`ucLine`、`ucValue`、`ucOk`…）。要接 Arduino 又不需要 mBlock 的話，[I2C 版](/sensors/unicam/arduino/index.md) 一次可以連續讀 16 個值，比較快。

```cpp
// 神攝手通用版（mBlock 版韌體）接一般 Arduino 板的串口（不經 mBot）：印出循線的近處偏移與角度
// 需要 MBC_Sensors v2.1.0（同上，不需要 Makeblock 函式庫）。UNO 用軟體串口 D10／D11；Mega 用 Serial1（D19 RX、D18 TX）
#include <SoftwareSerial.h>
#include <MBC_Sensors.h>

MBCPort cam;                    // 不指定連接埠，下面用 begin(串口)
#if defined(__AVR_ATmega2560__)
#define CAM_SERIAL Serial1
#else
SoftwareSerial camSerial(10, 11);   // RX = D10（接相機 TX＝IO1）、TX = D11（接相機 RX＝IO3，要分壓）
#define CAM_SERIAL camSerial
#endif

void setup() {
  Serial.begin(115200);
  CAM_SERIAL.begin(38400);
  cam.begin(CAM_SERIAL);
  delay(2000);
  Serial.println(ucOk(cam) ? "神攝手通用版 OK" : "沒有回應：檢查接線、韌體是不是 mBlock 版");
  ucSetMode(cam, 41);           // 循線 ① 黑線
}

void loop() {
  Serial.print("近處偏移 ");
  Serial.print(ucLine(cam, 0));
  Serial.print("  角度 ");
  Serial.print(ucLine(cam, 3));
  Serial.print("  路口 ");
  Serial.println(ucLine(cam, 6));
  delay(100);
}
```

## 常見問題

- **讀值一直是 −32768？** → 先用「感應器正常？」：否＝連接埠選錯、插座片沒插緊、相機燒的不是 mBlock 版韌體；是＝模式不對，用「目前模式編號」看相機在哪個模式（顏色追蹤 ③＝13、循線黑線＝41）。
- **積木區沒有「神攝手通用版」？** → 拖進去的是舊版擴展（v2.0.0 以前）；照上面「安裝擴展」換 v2.1.0。
- **在相機選單換了模式，積木多久跟著換？** → 最慢 0.1 秒（模式編號的快取時間）。
- **一直「沒找到」？** → 相機上還沒教目標顏色，或燈光差太多；看相機螢幕有沒有框住色塊。
- **能不能用即時模式（不上傳）？** → 不行，這個擴展只支援上傳模式。
