# ∿ EXP6 通用 I2C 版開發指南

[🔙 回到 EXP6 產品介紹](/sensors/exp6/index.md)

EXP6 的通用 I2C 版，讓 **Arduino、ESP32、樹莓派**也能直接驅動 6 個 LEGO SPIKE 馬達與感應器：定速、走角度、雙馬達同步、讀角度與速度、讀顏色／超音波／力量感應器，全部用 I2C 命令完成。

> [!IMPORTANT]
> 共通的讀寫規則、狀態暫存器與 Arduino 共用函式，請先看 [MBC 通用 I2C 協議](/i2c-protocol.md)。

## 📡 基本資訊

| 項目 | 內容 |
| :--- | :--- |
| I2C 位址 | `0x6E` |
| 型號字串 `0x07` | `EXP6` |
| 款式 `0x06` | `[6, 電池節數]`（埠數、2 或 3 節電池） |
| 安全機制 | **看門狗**：預設 500 ms 內沒有任何 I2C 讀寫，未在走角度的馬達自動滑行停止 |

## 1️⃣ 總覽

| 暫存器 | 方向 | 長度 | 內容 |
| :---: | :---: | :---: | :--- |
| `0x10` | W | 4 | 原始命令 `[L1, L2, L3, L4]`（與 Pybricks 版相同；`[0,0,0,0]` = 全部停止並重置） |
| `0x11` | R | 8 | 總覽合併包（= `0x12` ~ `0x13`） |
| `0x12` | R | 6 | 6 個埠接的裝置：`0` 無、`1` 力量、`3` 顏色、`4` 超音波、`5` 馬達、`7` 其他 |
| `0x13` | R | 2 | 電池電壓 uint16，mV |

## 2️⃣ 雙馬達同步與設定

| 暫存器 | 方向 | 長度 | 內容 |
| :---: | :---: | :---: | :--- |
| `0x20` | W | 4~5 | 雙馬達同步 `[左埠 1~6, 右埠 1~6, 左速 -100~100, 右速 -100~100, 停止方式(選填)]`；兩速皆 0 = 停止 |
| `0x22` | RW | 1 | 看門狗逾時，單位 100 ms（`0` = 關閉，預設 `5` = 500 ms）。主程式有長 `delay()` 時請調大或關閉 |

## 3️⃣ 狀態旗標 `0x32`

| 位元／暫存器 | 內容 |
| :---: | :--- |
| bit1 | 有馬達在轉動 |
| bit2 | 看門狗曾停止馬達（收到下一筆命令後清除） |
| `0x34` | 等待執行的命令數 |
| `0x35` | 命令佇列溢位次數（命令送太快被丟棄） |

## 🔌 各埠控制（埠 1~6）

每個埠有自己的一段暫存器，**基底 B = `0x40` + `0x10` × (埠號 − 1)**：埠 1 = `0x40`、埠 2 = `0x50`、…、埠 6 = `0x90`。

| 暫存器 | 方向 | 長度 | 內容 |
| :---: | :---: | :---: | :--- |
| B+`0x00` | W | 1~5 | 埠命令 `[命令, 參數…]`（見下表） |
| B+`0x01` | R | 8 | 埠合併包（= B+`0x02` ~ B+`0x05`） |
| B+`0x02` | R | 1 | 裝置類型（同 `0x12`） |
| B+`0x03` | R | 4 | 馬達角度 int32，度 |
| B+`0x04` | R | 2 | 馬達速度 int16，度/秒 |
| B+`0x05` | R | 1 | 馬達狀態：低 4 位元 = 模式；bit4 走角度中、bit5 反向安裝、bit6 馬達就緒 |
| B+`0x06` | R | 4 | 感應器原始值 int32（顏色感應器 = 顏色、反射光、R、G、B） |

### 埠命令

| 命令 | 參數 | 動作 |
| :---: | :--- | :--- |
| `0x01` | — | 滑行停止 |
| `0x02` | — | 煞車 |
| `0x03` | — | 鎖定在目前角度 |
| `0x10` | 速度 -100 ~ 100 | 定速轉動（PID 閉迴路） |
| `0x11` | 功率 -100 ~ 100、加速度 0 ~ 100（選填） | 開迴路 PWM |
| `0x20` | 速度 1 ~ 100、角度 int16 -2499 ~ 2499、停止方式 | 轉相對角度 |
| `0x21` | 速度 1 ~ 100、角度 0 ~ 359、停止方式 | 轉到絕對角度（自動走最短路徑） |
| `0x30` | — | 角度歸零 |
| `0x31` | `0` 正裝 / `1` 反裝 | 設定安裝方向（切換時角度歸零） |
| `0x32` | kp, ki, kd（0 ~ 100，50 = 原廠值） | 調整 PID 倍率 |

**停止方式：** `0` 滑行、`1` 煞車、`2` 鎖死、`3` 繼續轉。走角度的途中再下走角度命令會被忽略，其他命令會立即接管。

## 💻 Arduino 範例

```cpp
#include <Wire.h>

const uint8_t EXP6 = 0x6E;

void sendCmd(const uint8_t *bytes, uint8_t n) {
  Wire.beginTransmission(EXP6);
  Wire.write(bytes, n);
  Wire.endTransmission();
}

bool iicRead(uint8_t reg, uint8_t *buf, uint8_t n) {
  Wire.beginTransmission(EXP6);
  Wire.write(reg);
  if (Wire.endTransmission() != 0) return false;
  if (Wire.requestFrom(EXP6, n) != n) return false;
  for (uint8_t i = 0; i < n; i++) buf[i] = Wire.read();
  return true;
}

void setup() {
  Serial.begin(115200);
  Wire.begin();

  // 範例裡有 delay(2000)，先關閉看門狗（正式程式建議保留，改成定期讀寫）
  uint8_t wd[] = { 0x22, 0 };
  sendCmd(wd, 2);

  // 埠 1 的馬達以 50% 速度定速轉動
  uint8_t run[] = { 0x40, 0x10, 50 };
  sendCmd(run, 3);
  delay(2000);

  // 埠 1 往正方向轉 360 度，到達後煞車
  uint8_t deg[] = { 0x40, 0x20, 40, 0x01, 0x68, 1 };   // 360 = 0x0168
  sendCmd(deg, 6);
}

void loop() {
  uint8_t d[4];
  if (iicRead(0x43, d, 4)) {                         // 埠 1 角度
    int32_t angle = ((int32_t)d[0] << 24) | ((int32_t)d[1] << 16) | (d[2] << 8) | d[3];
    Serial.println(angle);
  }
  delay(100);                                        // 定期讀寫也能讓看門狗保持運作
}
```

> [!WARNING]
> **EXP6 的 I2C 接線和其他 MBC 產品相反**：原本 TX 腳 = SDA、RX 腳 = SCL。請依板上標示接線，接反時主機會讀不到裝置。
