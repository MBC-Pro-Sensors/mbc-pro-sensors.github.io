# MBC EXP6 6-Port Motor Expander (for LEGO® SPIKE™) × Arduino (UART)

> [!WARNING]
> **EXP6 × Arduino (UART): Under development — not yet supported.** This page is kept for reference while we develop and test it; for now please use the EXP6 with [SPIKE Prime or Robot Inventor](/en/sensors/exp6/index.md).
<!-- exp6-arduino-dev -->

The EXP6 **cannot use I2C** with Arduino (the host-port isolator only sends one way); the approach under development uses a **serial port (UART)**.

- Examples and wiring under development (for reference): [EXP6 × Arduino examples](/en/sensors/exp6/arduino-examples.md)
- Interactive tutorial under development (for reference): [EXP6 × Arduino interactive tutorial](/en/learn/exp6/arduino.html)
- What works now: [SPIKE Prime / Robot Inventor](/en/sensors/exp6/spike/index.md)
