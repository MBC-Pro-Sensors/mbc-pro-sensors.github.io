# Vision Sensor (School Edition) × MATRIX Mini R4

[🔙 Back to Vision Sensor (School Edition)](/en/sensors/esp32cam/index.md)

On MATRIX the Vision Sensor (School Edition) talks over serial and is read with the built-in **mVision** camera blocks (not I2C).

## mVision data slots

<figure class="ref-fig"><img src="/images/figures/common/packet-mvision.svg" alt="mVision packet" loading="lazy"></figure>

| Slot | Value | Range | Meaning |
| :--- | :--- | :--- | :--- |
| 0 | [hue](/en/sensors/esp32cam/reference.md#v01) | -1~100 | 0~100；255 = 黑白灰（−1 不能放 uint16，MATRIX 定案 §7）；hue of sample point S1, 0~100 (hue ring 0~240 scaled); −1 = black/white/grey (saturation < 10); 0 when S1 is not set |
| 1 | [saturation](/en/sensors/esp32cam/reference.md#v02) | 0~100 | saturation of sample point S1, 0~100 |
| 2 | [brightness](/en/sensors/esp32cam/reference.md#v03) | 0~100 | brightness (HSV value) of sample point S1, 0~100 |
| 3 | [motion](/en/sensors/esp32cam/reference.md#v04) | 0~100 | whole-frame motion 0~100 (more change = larger) |
| 4 | [blob X](/en/sensors/esp32cam/reference.md#v05) | 0~100 | blob centre X 0~100, left = 0; 0 when not found |
| 5 | [blob Y](/en/sensors/esp32cam/reference.md#v06) | 0~75 | blob centre Y 0~75, bottom = 0, top = 75; 0 when not found |
| 6 | [blob width](/en/sensors/esp32cam/reference.md#v07) | 0~100 | blob width W 0~100; 0 = not found |
| 7 | [blob height](/en/sensors/esp32cam/reference.md#v08) | 0~75 | blob height H 0~75; 0 when not found |
| 8 | [blob area](/en/sensors/esp32cam/reference.md#v09) | 0~7500 | W×H；W×H (0~7500); 0 when not found |
| 9 | [blob found](/en/sensors/esp32cam/reference.md#v0a) | 0~1 | 1 = a blob of the target colour is in view (W > 0), 0 = none |

[0xAA][N][N 個 uint16 小端][xor]，xor = AA ^ N ^ 所有資料 byte；N ≤ 10（MATRIXblock 只宣告 CamData[10]）；學校版每 20 ms 一包

## Sources and assumptions

Generated by `_build/gen-reference.mjs` from `_build/protocol/cam_school.json` (single source of truth, transcribed from the 2026-10-21 protocol decisions).

- hw0 = 1（共識 #6：神攝手 1 = 學校版）；model 字串 CAMSCH 照任務指定（韌體原本沒有型號欄位）。
- D4：I2C 0x4C 用 SDA = IO3、SCL = IO1（沿 PS4 Wire.setPins 慣例），與 EV3／SPIKE 串口模式二選一編譯；ESP32 從機不能時脈延展，onReceive 預載 32 B；頁面標「硬體已確認，上機待測」。mBlock 用同一組腳 Serial.begin(38400, SERIAL_8N1, 3, 1)。
- EV3 六個模式全部鎖住照盤點（模式 3／5 的 −1 已在 #65 修成符號延伸）；EV3 定案最後的 golden 備註把 cam_school 列進「模式 5 改 ID」是筆誤（定案表本身寫「—」；模式 5 仍是 [色相, 飽和]），所以 ev3IdMode = null。
- SPIKE 模式 9 鎖住，只有 byte 8~9（v[4]）從 0 改成面積 W×H；模式 6 改 [X, Y, 面積]；模式 8 = [0x4C | 1<<8, 2, 韌體版, 更新序號]；模式 1~4 維持 0。
- SPIKE 模式 0 的「面積」是 map(像素面積 0~5000 → 0~100)，跟值表 09 的 W×H 不同，鎖住不改（照盤點）。
- mVision：N = 10（idx 0~9），色相 −1 送 255；每 20 ms 一包（B-6）；不做 0x22／大通道（hosts.matrix = false）。
- 0A 有找到色塊 = W > 0（盤點：W 0 = 沒找到）；F3 b1 同這個值。
- 值 05~08 的「沒找到 = 0」照盤點 §0；色塊 Y 下 = 0、上 = 75 照盤點（map(bestY,120,0,0,75)）。
- 沒有寫入命令（韌體無法從程式改目標顏色／補光燈）。
