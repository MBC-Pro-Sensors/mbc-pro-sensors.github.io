# Line Follower 8-ch × micro:bit (MakeCode extension)

[🔙 Back to Line Follower 8-ch](/en/sensors/line8/index.md)

The universal I2C edition of the Line Follower 8-ch works with BBC micro:bit V1 / V2 through the MakeCode extension **pxt-mbc-sensors v2** (which speaks [MBC I2C protocol v2](/en/i2c-protocol.md)). Installation and hardware notes (3.3 V, power): [micro:bit overview](/en/microbit.md).

## Reporter blocks

| Block | Returns | Id | Meaning |
| :--- | :--- | :--- | :--- |
| MBC line position | -8~+8 | [`01`](/en/sensors/line8/reference.md#v01) | which channel the line is under: −8 (far left) to +8 (far right), 0 = centre; seen from behind the robot, negative = left |
| MBC fine line position | -100~+100 | [`02`](/en/sensors/line8/reference.md#v02) | sub-channel position: −100 to +100, 0 = centre, negative = left (same sign as line position) |
| MBC line width | 0~8 路 | [`03`](/en/sensors/line8/reference.md#v03) | number of channels on the line, 0~8; 0 = no line |
| MBC line segments | 0~4 | [`04`](/en/sensors/line8/reference.md#v04) | number of separate line segments: 0 = lost, 1 = one line, ≥2 = fork / crossing |
| MBC line bitmap | 0~255 bit | [`05`](/en/sensors/line8/reference.md#v05) | bit0 = channel 1 (left) … bit7 = channel 8; 1 = that channel sees the line |
| MBC last exit direction | -8~+8 | [`06`](/en/sensors/line8/reference.md#v06) | where the line was before it was lost: −8 to +8 (negative = left); keeps the last value |
| MBC threshold | 1~99 | [`07`](/en/sensors/line8/reference.md#v07) | reflect threshold for 'on line', 1~99, default 50; set with E4 |
| MBC channel [1~8] reflect | 0~100 | [`10~17`](/en/sensors/line8/reference.md#v10) | calibrated reflect of channel 1~8, 0~100 (channel 1 = left); ids 10~17 |

## Command blocks

| Block | Id | Meaning |
| :--- | :--- | :--- |
| MBC set black line | [`E0`](/en/sensors/line8/reference.md#ce0) | follow a black line (default) |
| MBC set white line | [`E1`](/en/sensors/line8/reference.md#ce1) | follow a white line (F3 b1 = 1) |
| MBC calibrate black | [`E2`](/en/sensors/line8/reference.md#ce2) | store the current reading as black (sensor over the black line), ~50 ms; saved to EEPROM |
| MBC calibrate white | [`E3`](/en/sensors/line8/reference.md#ce3) | store the current reading as white (sensor over the white surface), ~50 ms; saved to EEPROM |
| MBC set threshold [n] | [`E4`](/en/sensors/line8/reference.md#ce4) | threshold 1~99 (RAM only, back to 50 after reboot) |
| MBC auto calibrate (5 s) | [`E7`](/en/sensors/line8/reference.md#ce7) | sweep the sensor across black line and white surface for 5 s; min/max become the references; F3 b2 = 1 meanwhile |

## Status

| bit | Name | Meaning |
| :--- | :--- | :--- |
| b0 | ready (`ready`) | always 1 |
| b1 | white line mode (`whiteMode`) | 1 = following a white line |
| b2 | calibrating (`calibrating`) | E2/E3/E7 in progress; new calibration commands are ignored |
| b3 | line lost (`lost`) | segment count = 0 |
| b4 | fork (`fork`) | segment count ≥ 2 |

## JavaScript

```typescript
basic.forever(function () {
    let linePos = MBC.readValue(0x16, 0x01)   // line position
    basic.showNumber(linePos)
    basic.pause(100)
})
```

## Sources and assumptions

Generated by `_build/gen-reference.mjs` from `_build/protocol/line8.json` (single source of truth, transcribed from the 2026-10-21 protocol decisions).

- B-11：細位置 02 與線位置 01 同號（負 = 左）；v1 韌體註解寫反，程式碼同號。
- B-12：E7 五秒動態校準補回（v1 的 0x20=0x01），定案表沒列。
- SPIKE 教育版模式 0 的 byte 8~15 補 0（#65 已改，使用者保留）。
- EV3 模式 4 與模式 2 相同內容；模式 3 改壓線位元圖（#67）。
- mBlock 舊版：MBC_MBLOCK_LEGACY=1 時逐 byte 同 2026-10-21 統一後韌體，0x0B 回 1。
- The extension reads `Int16LE` and pauses 2 ms after writing the id (D5).
