Official LEGO SPIKE App: control EXP6 with Python

The blocks in the official LEGO SPIKE App can only control LEGO's own parts. EXP6 is not a LEGO device, so there are no blocks for it; use Python in the official App instead. Install the EXP6 library on the hub once. After that, every Python project only needs one line, from MBC_exp6_SPIKE_App_Lib import MBC_EXP6, to use it.

1. Install the library on the hub (only once)

  1. Download install_exp6_lib.llsp3 (the installer program).
  2. Connect the hub to the official LEGO SPIKE App by USB or Bluetooth, then choose "File" → "Open" and pick this file.
  3. Press ▶ to run it once. When the Console at the bottom shows "Installation Successful!", you are done.

If you reinstall or update the hub firmware, the library is wiped and you have to run the installer once more.

2. The quickest way: open an example

The 5 examples below are already written. Download one, open it in the official App and press ▶ to run it (plug the EXP6 Host cable into hub port C and connect the EXP6 battery):

  1. Example 1: one motor turns one full turn
  2. Example 2: three motors turn together
  3. Example 3: light switch (the colour sensor controls a motor)
  4. Example 4: control a motor with the hub buttons
  5. Example 5: two-wheel car drives a square

What each example does, how to wire it and what you will see are on the EXP6 SPIKE beginner examples page. Every command is explained in the official App section.

The programs inside the examples are the same files as on the Chinese page, so the comments in the code are in Chinese. The examples page explains every line in English.

3. How it differs from the other two ways

  • Create the object with MBC_EXP6(port.C) (the official App uses port.C; Pybricks uses the number 3).
  • The official App has no automatic protection: at the start, wait 2 seconds so the motors are ready, and always end your program with exp6.stop_all(1), or the motors keep doing the last command.
  • For a turn, only the sign of the degrees decides the direction. Reflected light is worked out from red, green and blue, so the number is a little different from Pybricks. The absolute angle goes from -180 to 179.
  • Before you switch to another way (Pybricks or the MBC Blocks website), power EXP6 off once (turn the hub off or unplug the Host cable).

The official App Python examples were written from the library, but they have not yet been run one by one on every App version and hub. If something does not work, please tell us.
