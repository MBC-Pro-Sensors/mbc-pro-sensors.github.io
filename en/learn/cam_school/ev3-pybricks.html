Read the Sharpshooter Vision on the EV3 with MicroPython in three steps

MicroPython on the EV3 always goes in this order. First import. Then create an object and give the sensor a name. Last, use that name to read values. First pick Pybricks v4 or EV3 MicroPython v2 above. Then follow the steps on the left, and the program on the right grows with you. Drag the blob in the pretend camera picture and change its colour and size to see what the program prints.

Your software:
1

Import the libraryImport the modules

The first thing your program does is tell Pybricks: "I want to use the Sharpshooter Vision library". Without this line, the hub does not know what MBC_CAM_SCHOOL means, and you get a NameError.

Pick one library. Both work the same way. Only the import line is different.

  1. Download the library (save the file and keep its name): MBC_cam_school.py (only this sensor) or MBC_sensors.py (the all-in-one library). You picked MBC_cam_school.py.
  2. Open code.pybricks.com in Chrome. Follow the steps on the site to put the Pybricks firmware on the EV3 (the release version already includes the EV3 firmware).
  3. Press "Import a file" in the file list on the left. Import the library into the same project.
  4. Do not rename the file, and do not put it in a sub-folder.
  5. Go back to your main program. Write the lines below at the very top (marked ① in the program on the right).

EV3 MicroPython v2 cannot use the MBC library (it does not have the PUPDevice the library needs). Use the built-in Ev3devSensor instead, and read the sensor "modes" directly. You do not need to download any file.

  1. Start the EV3 from the official LEGO EV3 MicroPython microSD card.
  2. In VS Code, install the "LEGO MINDSTORMS EV3 MicroPython" extension and create a new project.
  3. Open main.py. Write the lines below at the very top (keep line 1, the one that starts with #!).
  4. Press F5 to download it to the EV3 and run it.

Which port is the sensor on?

Turn on multitasking?

The 1 in the program is the port number: EV3 1~4 = S1~S4. You can also write Port.S1, but then you also need from pybricks.parameters import Port.

Ev3devSensor needs the form Port.S1 (a plain number does not work), so step 1 also imports Port.

3

Use a functionRead a value

You always write "cam.function_name()": the name, a dot, then the function. Click a function, and the program and output change to its example.

You write "cam.read('mode name')[which one]". Each mode sends back several numbers at once. Use [0], [1]… to take one of them (counting starts at 0). Use only one mode in the same loop: the EV3 needs about 0.5 s every time it changes mode. Click a reading, and the program and output change to its example.

Good to know

    
    
      
  1. Unplugging works differently in the two programs. Pybricks v4 with the MBC library: when the sensor cannot be read, you get the last value it read (or None if it has never been read). The computer prints one warning line, and the program keeps running. If you unplug while chasing a blob, the robot keeps turning towards the last place it saw it. To check the cable, use sensor_ok(). EV3 MicroPython v2 with Ev3devSensor: you get an OSError and the program stops. Plug it back in and run the program again. Tick "Unplug the sensor" on the right to see both.
    2. 
      
  2. Colours are set on the sensor, not in the program. The hue comes from the sample point of "Setup 1: COLOR", and the blob comes from the colour picked in "Setup 2: TRACK". You can only set them with the buttons on the sensor. Without Setup 1 the hue is always 0, the same as red, so the program thinks it sees red.
    3. 
      
  3. Check that a blob is found first. When nothing is found, blob X, Y, width, height and area are all 0, which looks like "a blob in the bottom-left corner". So check found() (or blob width = 0) first, then look at the position.
    4. 
      
  4. On the EV3 almost everything is mode 1. In the library, hue() to blob_h(), found(), area(), blob_xya() and read_all() all read mode 1, so reading them together is not slower. area() is width × height. The EV3 cannot read device_id() or firmware_version() (SPIKE only).
    5. 
      
  5. Directions: standing behind the robot and looking forward, X is left/right with the centre at about 50, so X − 50 is negative on the left and positive on the right. Y is up/down: small at the bottom, big at the top. If left and right are swapped, switch H-Mirror in the camera menu on the sensor. Motion is only accurate when the robot stands still.
