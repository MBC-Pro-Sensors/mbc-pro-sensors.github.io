LEGO SPIKE App: read the Sharpshooter WRO edition with Python

The blocks in the official LEGO SPIKE App only know LEGO's own sensors. The WRO edition is not a colour sensor (its device ID is 95), so the blocks cannot read it. Use Python in the official App instead. Python in the official App can read the hue and saturation of every point. Three steps get you started.

1. Start a Python project

Open the official LEGO SPIKE App → New Project → choose "Python" (not Word Blocks).

2. The quickest way: open an example

The 5 examples below already include the "HUE12 reader helper". Download one, open it in the official App and change it as you like:

  1. Example 1: Read the hue at point 1
  2. Example 2: Is point 1 red?
  3. Example 3: How many of the 12 points see a colour?
  4. Example 4: Turn by colour
  5. Example 5: Look at the object's colour and decide which side to go around

The explanation, wiring and "what you should see" for each example are on the WRO edition SPIKE examples page. The comments inside the example programs are in Chinese; that page explains every line in English.

3. The values you get

The sensor watches 12 points on the picture. Each point has a hue (0 to 255; 255 = this point has no colour; 240 to 245 = white; 246 to 250 = black) and a saturation. Set the positions of the 12 points on the sensor first; the examples page shows how in "Before you start".

So far the official App Python examples have only had a syntax check. They have not yet been run one by one on every App version and hub. If something does not work, please tell us.

Want blocks or colour names?

To build with blocks: use the MBC SPIKE Blocks website instead (free, no login; the hub needs Pybricks firmware). To get colour names like "red, blue, green" straight away: use Pybricks (MicroPython) or Pybricks blocks with the MBC library.
