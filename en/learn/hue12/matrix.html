MBC Sharpshooter Vision (WRO edition, HUE12) × MATRIX Mini R4 (MATRIXblock)

Read the Sharpshooter Vision (WRO edition, HUE12) with MATRIXblock in three steps

In MATRIXblock, the software for the MATRIX Mini R4, the Sharpshooter Vision (WRO edition, HUE12) shows up as an mVision camera (serial port), so the built-in mVision blocks can read it and no library is needed. First put MVision Begin in Setup of "Mini Begin", then MVision Polling in Loop, and finally the MVision data blocks in its "Data Available" part. Follow the steps on the left and the blocks on the right build up; these pictures are drawn by MATRIXblock's own block code, so they look the same as in the software.

MATRIXblock is the free block software from MATRIX (installed in C:\matrixblock-r4\ by default). Buy the MATRIX edition of the sensor and plug it into the Mini R4 serial port used by the mVision camera.

1

Set up: start mVision

On the MATRIX, the Sharpshooter Vision (WRO edition, HUE12) acts as an mVision camera on the serial port, not I2C. The first thing in the program is "MVision Begin" inside "Setup" of the blue "Mini Begin" block.

Wiring: plug the sensor into the Mini R4 serial port used by the mVision camera (Serial1, 115200). There is no port to pick.

  1. Open MATRIXblock. A new project already has a blue "Mini Begin" block (if not, drag one from the "Mini Core" category).
  2. Click the "Sensing" category and find "MVision Begin".
  3. Put it inside "Setup".
2

Put "MVision Polling" in the loop

"MVision Polling, Data Available" waits for the next packet from the sensor. When one arrives it runs the top part; if nothing comes (about 0.5 seconds) it runs "Not Available". So the loop needs no extra wait.

  1. Drag "MVision Polling, Data Available / Not Available" from "Sensing" into "Loop".
  2. Inside "Not Available", add "USB Serial Print No data received with New Line" (in the "Serial" category), so you can see when it is unplugged.

Leave "UART: On" and "Baud: 9600" on "Mini Begin" as they are: the examples use "USB Serial Print … with New Line" to show values in the Information Window (set the Information Window to 9600 too).

3

Use the MVision data blocks

The "MVision 0 Data" block in "Sensing" picks a data slot in its dropdown; each slot is one value from the Sharpshooter Vision (WRO edition, HUE12). The example goes inside the "Data Available" part. Click a function and the blocks and output change to its example.

Things to know

    
    
      
  1. Wiring: plug the Sharpshooter Vision (WRO edition, HUE12) into the Mini R4 serial port used by the mVision camera (Serial1, 115200), not an I2C port. Use only the "MVision" blocks, not the colour sensor blocks.
    2. 
      
  2. Decode it like the WRO example: the WRO edition packs data the same way as before, matching the HUE12_AS_mVisionSensor_v1.0.8.mbr4 example WRO 2026 teams use (colour codes with "mod 256" and "floor of / 256"; vividness with /1, /16, /256, /4096 then mod 16).
    3. 
      
  3. Use data 0 to 8 only: the WRO edition sends 9 slots per packet (data 0 to 8); data 9 stays 0. Never use "10" in the dropdown.
    4. 
      
  4. Decimals: "mod" and "floor" give decimal numbers, so they print with .00 (for example 80.00). Comparing them works fine.
    5. 
      
  5. When it is unplugged: "MVision Polling" waits about 0.5 seconds, then runs the "Not Available" part; the data stays at the last values received.
