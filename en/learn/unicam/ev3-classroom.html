Read Sharpshooter Vision with EV3 Classroom in three steps

On the EV3, the Sharpshooter Vision shows up as a LEGO Infrared Sensor, so you do not import a library or add an extension: you read it with the Infrared Sensor blocks. Proximity gives the camera mode number, the heading and proximity of the 4 beacon channels are the 8 main values, and the 4 remote channels are 4 more values. What each value means depends on the mode chosen in the camera menu. Work down the steps on the left and the blocks on the right grow with you; these block pictures were built in EV3 Classroom 1.5.3 and exported straight from the software (English interface).

v1 not yet hardware-verifiedThe value layout is final and passed computer tests; real-hardware numbers (fps, line thresholds, I2C pins) may change after hardware testing.

1

Start: program start + repeat forever, pick the camera mode

You read the sensor again and again, every 0.1 seconds.

  1. Open EV3 Classroom and press "New Project".
  2. Drag "forever" from "Control" and attach it under the yellow "when program starts".
  3. Drag a "wait 1 seconds" block into forever and change the number to 0.1.
  4. Plug the camera into port 1 with an EV3 cable (the hub powers it). Choose the camera mode and sub-option in the camera's MODE menu and click the same mode number below (mode number = camera mode × 10 + sub-option). The table in step 2 changes to what each value means in that mode.
2

Meet the reading blocks (Infrared Sensor)

Use the Infrared Sensor blocks in "Sensors"; the number at the front of each block is the port: choose 1. The table shows, for the mode you picked in step 1, which block reads each value, what you get and how to read it:

Every value is a whole number from −127 to 100. Keep one program on Beacon (or on Remote) only: every infrared mode change makes the EV3 pause for about 0.5 seconds. To split tens and ones, use the math blocks: divide by 10 and round down, and the remainder after dividing by 10.

3

Show it on the EV3 screen

Put the reading block into "write … at line …" from "Display", use "join" from "Operators" to put a name in front (for example C1), and start with "clear display". Functions are grouped by camera mode; dashed ones belong to another mode (clicking one switches the mode for you). Click a function and the blocks and result change to its example.

Simulated camera view: drag things in the picture and watch the output change

The view is a sketch: values come straight from where things are on screen (X 0–159 left→right, Y 0–119 top→bottom, area % = width × height ÷ whole picture); a hue code is the color the paper or block really has (red 0, yellow 40, green 80, blue 160, purple 200, white table 244, black tape 252). It is not the camera's own algorithm, and real numbers vary with the light. Color tracking assumes 4 colors were taught on the camera: color 1 red, 2 green, 3 blue, 4 yellow. In object detection you pick each shape yourself (the camera does not judge it here); objects 1, 2… are sorted by area, largest first; X, Y is the shape's centroid (white dot), the dashed box is its bounding box, and the angle is the rotation you set.

An example for every function

Every function has a small program you can copy (camera in port 1); the badge shows which modes it works in. "Try it" jumps to step 3 (and switches the mode if needed).

Line following (mode 41 black line, left wheel B, right wheel C)

        

        
!Beacon channel 1 heading = near offset (line on the left = negative): left wheel 30 + offset×0.3, right wheel 30 − offset×0.3, so it turns toward the line. Not turning enough? Make 0.3 bigger.

      

    

  


  

    
Good to know

    
    
      
  1. Plug the camera into port 1. For another port, change the port number on the block. Switch the EV3 on first, then plug in the camera; if the numbers never change, unplug it and plug it in again.
    2. 
      
  2. The mode number must match the camera menu. An EV3 program cannot switch the camera mode, and one value means different things in different modes; read the mode number with Proximity and check it at the start.
    3. 
      
  3. Use Beacon only or Remote only in one program. Each infrared mode change makes the EV3 pause for about 0.5 seconds, and a racing robot can lose control.
    4. 
      
  4. When the camera is unplugged: the EV3 cannot read it, the number becomes "not a number" and the screen shows ----; each reading waits about 1.2 seconds. The program does not stop and recovers when you plug it back in. Tick "Unplug the sensor" to see it.
    5. 
      
  5. Colours are taught on the camera. "Target 1" is colour 1; sample spots are also set on the camera. The EV3 only reads the numbers.
    6. 
      
  6. More: EV3 reading guide, Value reference: EV3. EV3 Classroom has only English and Simplified Chinese interfaces.
    7.
