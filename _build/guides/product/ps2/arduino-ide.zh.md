### 讓手把連上接收器

PS2 的 2.4G 手把和它的接收頭是**原廠成對**的，不用按任何配對鍵。

1. 接收器接好、主機開機。
2. **打開手把電源**，手把會自己連上。
3. 看接收器板子上的**綠燈**：**亮著＝還沒接到手把**；**熄掉＝已經接到手把**。
4. 手把上的 **ANALOG（或 MODE）燈要亮**，搖桿才有數值。接收器一接上手把會自動切到這個模式；燈沒亮就按一下手把中間的 ANALOG 鍵。

> [!CAUTION]
> 2.4GHz 是公共頻段，跟 Wi-Fi、微波爐共用。同一場地有 **12 套以上**同時使用時可能互相干擾，這種場合建議改用藍牙版（PS4／PS5）。

> [!WARNING]
> **只按 ■ 時，十六鍵（編號 `01`）= `0x8000` = -32768**，跟讀不到時的 `MBC_NONE` 一模一樣。要分辨「讀不到」，用 `mbcReadMany` 回傳的 true／false，不要拿 -32768 判斷：`int16_t b; if (mbcReadMany(0x42, 0x01, 1, &b)) { … }`，回 true 就是有讀到，再把 `(uint16_t)b` 當十六鍵用。
