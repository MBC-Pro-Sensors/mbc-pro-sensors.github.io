MBC 循行者 16 路 × micro:bit（MakeCode）

三個步驟用 micro:bit 讀循行者

在 MakeCode for micro:bit 上，先加入 MBC 擴充，再在「當啟動時」等感應器就緒，最後把讀值積木放進「重複無限次」。左邊一步一步做，右邊的積木會跟著長出來；這些積木圖是用 MakeCode 自己的渲染器畫的，跟你在編輯器看到的一樣。右上角可以切到 JavaScript，跟 MakeCode 右上的切換一樣。

MakeCode 免費、免登入，用 Chrome 或 Edge 打開就能寫；程式按「下載」存成 .hex，拖進 micro:bit 就會跑。

1

加入 MBC 擴充、接好線

micro:bit 本來不認得循行者。加入 MBC 擴充後，積木區會多一個「MBC 感應器」分類，循行者的積木都在「循行者」那一組。先選你的 micro:bit 版本，下面的硬體關卡會跟著換。

你的 micro:bit 是哪一版？（背面有寫 V2 的就是 V2）
  1. 打開 MakeCode，按「新專案」。
  2. 積木區最下面點「進階」→「擴充功能」。
  3. 搜尋框貼上 https://github.com/contactmbcrobot/pxt-mbc-sensors，按 Enter，點 mbc-sensors。
  4. 要中文積木：右上齒輪 →「Language」→ 繁體中文。
2

當啟動時：等感應器就緒

感應器開機要一點時間。程式一開始先等它準備好：有接好就打勾，沒接好就打叉，馬上知道線有沒有接對。

感應器的 I2C 位址
  1. 從「邏輯」拖「如果…那麼…否則」放進「當啟動時」。
  2. 從「MBC 感應器」→「更多」拖「等位址 … 的裝置就緒，最多 … 毫秒」放進條件，位址選 22（0x16）、填 3000。
  3. 從「基本」拖兩個「顯示 圖示」，一個選打勾、一個選打叉。
  4. 「重複無限次」裡先放「暫停 100 毫秒」。

3

使用讀值積木

「MBC 感應器 → 循行者」有讀線位置、光值、事件、校準等積木；「裝置」組是每款 MBC 感應器都有的共用積木。點一個功能，積木和輸出會換成它的範例。

模擬感應器（從車子後面往前看）：拖動黑線，看右邊的輸出怎麼變

模擬畫面是示意：數值換算簡化過，實際感應器可能差一兩格。圓圈裡是光值（0 = 黑、100 = 白）；紅框 = 那一路判斷在線上。

使用注意

    
  1. 拔線不會讓程式停：感應器讀不到時，讀值積木回 0（是／否積木回「否」），也不會印任何訊息。所以「線位置 = 0」可能是線在正中間，也可能是沒接好；要分清楚就用「位址 … 的裝置就緒？」。勾下面的「拔掉感應器」試試看：連「當循行者 丟線」都會觸發。
  2. 方向：站在車後面往前看，線在左邊是負數、右邊是正數；第 1 路在最左邊。
  3. 丟線時：線完全離開感應器時，線位置停在最後離開的那一側（−16／+16）；要判斷「真的看不到線」用「循行者 看到線？」或線寬等於 0。
  4. 8 路和 16 路都是 0x16：同一組 P19／P20 要接兩個循行者，先用「把位址 … 的裝置 改成位址 …」把其中一個改掉，第 2 步再選「改過的位址」。
  5. JavaScript 進階：mbc.readValue(22, 0x01) 可以直接讀任何一個 I2C 值（沒接好回 −32768），mbc.writeCmd(22, 0xE0, []) 送命令；編號看產品網站的 I2C 指令參考。
