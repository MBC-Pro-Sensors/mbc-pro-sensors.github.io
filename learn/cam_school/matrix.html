MBC 神攝手 學校版 × MATRIX Mini R4（MATRIXblock）

三個步驟用 MATRIXblock 讀神攝手 學校版

在 MATRIX Mini R4 的 MATRIXblock 軟體裡，神攝手 學校版會被當成一台 mVision 攝影機（串口），用內建的 mVision 積木就能讀，不用裝函式庫：先在「Mini初始化」的設置裡放MVision 初始化，再在循環裡放MVision 輪詢，最後把MVision 數值積木放進「有數據」那一格。左邊一步一步做，右邊的積木會跟著長出來；這些積木圖是用 MATRIXblock 自己的積木程式畫的，跟你在軟體裡看到的一樣。

MATRIXblock 是 MATRIX 原廠的免費積木軟體（預設裝在 C:\matrixblock-r4\）。感應器要買 MATRIX 版，接 Mini R4 給 mVision 攝影機用的串口。

1

初始化：打開 mVision

神攝手 學校版在 MATRIX 上被當成一台 mVision 攝影機，走串口，不是 I2C。程式的第一件事，是在藍色「Mini初始化」積木的「設置」裡放「MVision 初始化」。

接線：感應器接 Mini R4 給 mVision 攝影機用的串口（Serial1，115200），不用選孔。

  1. 打開 MATRIXblock。新專案的工作區已經有一顆藍色的「Mini初始化」積木（沒有的話到「Mini Core」類別拖一顆）。
  2. 左邊積木類別點「偵測」，找到「MVision 初始化」。
  3. 把它放進「設置」。
2

在循環裡放「MVision 輪詢」

「MVision 輪詢，有數據」積木會等感應器送來新的一包資料，收到就跑上面那一格，等不到（約 0.5 秒）就跑「無數據」那一格，所以循環裡不用另外放等待。

  1. 從「偵測」拖「MVision 輪詢，有數據／無數據」放進「循環」。
  2. 在「無數據」裡放「USB序列埠輸出 沒有收到資料 並換行」（在「序列埠」類別），拔線時就看得出來。

「Mini初始化」上的「序列埠:On」「Baud:9600」不要改：範例用「USB序列埠輸出…並換行」把數值印在資訊窗口（資訊窗口的鮑率也選 9600）。

3

使用 MVision 數值積木

「偵測」裡的「MVision 0 數值」積木，下拉選單選第幾格資料，每一格是神攝手 學校版的一個值。範例放在「有數據」那一格裡面。點一個功能，積木和輸出會換成它的範例。

模擬感應器（相機看到的畫面）：拖動色塊，看右邊的輸出怎麼變

模擬畫面是示意：數值換算簡化過，實際感應器會因為光線差幾格。十字 = 取色點（感應器上「設定 1：COLOR」選的位置），色相讀的是十字那一點，沒有顏色時是 255；綠框 = 感應器追到的色塊（「設定 2：TRACK」選的顏色）。X 左 0、右 100；Y 下 0、上 75。

使用注意

    
    
      
  1. 接線：神攝手 學校版接 Mini R4 給 mVision 攝影機用的串口（Serial1，115200），不是 I2C 孔；程式只用「MVision」積木，不要用顏色感應器積木。
    2. 
      
  2. 先在感應器上設定：神攝手的取色點、追蹤顏色都在感應器背面的螢幕與按鍵設定（短按側鍵進選單），不用電腦；設定會自動存起來。
    3. 
      
  3. 只用資料 0 ～ 9，不要用 10：MATRIX 程式只準備了 10 格（資料 0 ～ 9），下拉選單的「10」讀到的是別的記憶體。
    4. 
      
  4. 拔線時：「MVision 輪詢」等不到資料（約 0.5 秒）就跑「無數據」那一格，資料停在上一次收到的值。這款走串口，不要用顏色感應器積木。
    5. 
      
  5. 跟 EV3／SPIKE 版一樣：資料的範圍跟 EV3、SPIKE 版相同，程式的想法可以直接搬過來。
