不匯入函式庫，用 Pybricks 內建積木讀神攝手（學校版）

神攝手（學校版）插在 SPIKE 上會被當成樂高顏色感應器，所以 Pybricks 內建的顏色感應器積木就讀得到：reflection()（反射光）和 ambient()（環境光）兩個數字，神攝手（學校版）在裡面各裝了一組值，用數學積木拆開就能用。左邊一步一步做，右邊的積木會跟著長出來；積木圖是直接從 Pybricks Code 拼好匯出的。

跟「Pybricks 積木（匯入函式庫）」差在哪？
  • 這頁：不用下載、匯入任何檔案，打開 Pybricks 就能拼；但只拿得到色相和色塊 X、Y。
  • 匯入函式庫：要先匯入 MBC_cam_school.py，但一次讀得到 15 個功能（例如飽和度、明度、色塊寬高面積、動態值），一個功能一個積木。

先確認：Pybricks 的積木模式要授權碼或 Patreon 贊助才能用。沒有授權可以直接寫 MicroPython，寫法一模一樣（右邊切到「對應的 MicroPython」）。

1

set up：建立顏色感應器、選孔

不用匯入函式庫：在黃色「set up」下面接 Pybricks 內建的顏色感應器積木（ColorSensor），選神攝手（學校版）插的孔，名字取 cam。

神攝手（學校版）插在哪個孔？
  1. 在 Pybricks Code 按「+」新增檔案，選用積木（blocks）寫。
  2. 從「Sensors（感應器）」拖出顏色感應器的設定積木（感應器圖示），接在「set up」下面，名字改成 cam（可以取任何英文名字），孔選上面那個。
2

program：讀 reflection() 和 ambient()

在「program」下面放「repeat while true」，裡面用「print」印出 cam reflected light（reflection）和 cam ambient light（ambient），最後「wait 100 ms」。Pybricks 讀 reflection 時會自動把感應器切到 SPIKE 模式 5、讀 ambient 時切到模式 7，神攝手（學校版）在這兩個模式各放一組數字：

reflection() 是整數，就是色相（−1＝黑白灰），不用修；ambient() 是小數 X.YY，小數點前是 X、小數兩位是 Y。

3

用數學積木拆開、使用

先用「Variables」的「set to」把讀到的值存進變數：r＝reflection，a＝ambient ×100 再四捨五入（round）。再用「Math」的 //（÷ 取整數）和 %（÷ 的餘數）拆成兩個值，印出來或拿來判斷。點一個功能，積木和輸出會換成它的範例。

模擬感應器（相機看到的畫面）：拖動色塊，看右邊的輸出怎麼變

模擬畫面是示意：數值換算簡化過，實際感應器會因為光線差幾格。十字 = 取色點（感應器上「設定 1：COLOR」選的位置），色相讀的是十字那一點；綠框 = 感應器追到的色塊（「設定 2：TRACK」選的顏色）。X 左 0、右 98；Y 下 1、上 75。

使用注意

    
    
      
  1. 只有 2 個數字。reflection() 和 ambient() 各一個，其他值讀不到（第 2 步表格下面有列）。要用請改 匯入函式庫的 Pybricks 積木。
    2. 
      
  2. ambient() 先 ×100 再 round：小數直接拆會有誤差（例如 70.03 × 100 可能是 7002.9999），四捨五入成整數再用 // 和 %。
    3. 
      
  3. 先在感應器上設定：「設定 1：COLOR」選取色點、「設定 2：TRACK」選要追的顏色；程式裡沒有地方設定。
    4. 
      
  4. 座標方向：X 左小右大（中間約 50）、Y 下小上大；沒找到色塊時 X、Y 都是 0。
    5. 
      
  5. 不要用「color」積木或顏色名稱比對。神攝手（學校版）放的是數字，一律存進變數用數字比大小。拔掉感應器時內建積木會出錯讓程式停下（函式庫版不會）。
    6. 
      
  6. 積木背後就是 MicroPython。Pybricks Code 右邊的程式窗格就是積木產生的程式，跟這頁「對應的 MicroPython」一樣。
