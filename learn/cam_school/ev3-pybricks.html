三個步驟在 EV3 上用 MicroPython 讀神攝手

在 EV3 上寫 MicroPython 一定照這個順序：先匯入，再建立物件、幫感應器取名字，最後才用這個名字去讀值。上面先選你用的是 Pybricks v4 還是 EV3 MicroPython v2，左邊一步一步做，右邊的程式會跟著長出來；在模擬的相機畫面裡拖動色塊、換顏色、調大小，就能看到程式會印出什麼。

你用的軟體：
1

匯入函式庫匯入模組

程式的第一件事是告訴 Pybricks「我要用神攝手的函式庫」。沒有這行，後面寫的 MBC_CAM_SCHOOL 主機看不懂，會出現 NameError。

選一種函式庫（兩種寫法完全一樣，只差 import 那一行）：

  1. 下載函式庫（存成檔案，檔名不要改）：MBC_cam_school.py（只接神攝手）或 MBC_sensors.py（統一函式庫）；你選的是 MBC_cam_school.py。
  2. 用 Chrome 打開 code.pybricks.com，照網站說明把 EV3 換成 Pybricks 韌體（正式版已內建 EV3 韌體）。
  3. 在左邊檔案區按「Import a file」，把函式庫匯入同一個專案。
  4. 檔名不要改，也不要放進子資料夾。
  5. 回到主程式，在最上面寫下面這幾行（右邊程式標 ① 的地方）。

EV3 MicroPython v2 不能用 MBC 函式庫（它少了函式庫需要的 PUPDevice），改用內建的 Ev3devSensor 直接讀感應器的「模式」。不用下載任何檔案。

  1. 用樂高官方 EV3 MicroPython 的 microSD 開機卡讓 EV3 開機。
  2. 在 VS Code 裝好「LEGO MINDSTORMS EV3 MicroPython」擴充套件，新增一個專案。
  3. 打開 main.py，在最上面寫下面這幾行（第 1 行 #! 那行要保留）。
  4. 寫好之後按 F5 下載到 EV3 執行。
2

建立物件：幫感應器取名字建立物件：告訴程式插哪個孔

一台車可能接好幾個感應器，所以要「建立一個物件」：告訴程式感應器接在哪個孔，並幫它取個名字。之後每次要讀值，都是叫這個名字。用 Ev3devSensor 建立一個物件：告訴程式感應器插在哪個孔，並幫它取個名字。之後讀值都是叫這個名字。

要不要開啟多工？

程式裡的 1 就是孔位編號：EV3 1~4 = S1~S4。也可以寫成 Port.S1，但要多匯入 from pybricks.parameters import Port。

Ev3devSensor 一定要寫成 Port.S1（不能只寫數字），所以第 1 步多匯入了 Port。

3

使用功能讀值

寫法都是「cam.功能名稱()」：名字＋小數點＋功能。點一個功能，程式和輸出會換成它的範例。

寫法是「cam.read('模式名稱')[第幾個]」：每個模式一次送回好幾個數字，用 [0]、[1]… 拿第幾個（從 0 開始數）。同一個迴圈只用一種模式：EV3 每換一次模式要等約 0.5 秒。點一個讀值，程式和輸出會換成它的範例。

模擬感應器（相機看到的畫面）：拖動色塊，看右邊的輸出怎麼變

模擬畫面是示意：數值換算簡化過，實際感應器會因為光線差幾格。十字 = 取色點（感應器上「設定 1：COLOR」選的位置），色相、飽和度、明度讀的是十字那一點；綠框 = 感應器追到的色塊（「設定 2：TRACK」選的顏色）。X 左 0、右 98；Y 下 1、上 75。

使用注意

    
    
      
  1. 拔線時兩種軟體不一樣。Pybricks v4 的 MBC 函式庫：讀不到時回傳上一次讀到的值（從來沒讀到過就回傳 None），電腦畫面印一行提醒，程式不會停；追色塊時拔線，車子會照最後看到的位置繼續轉。要知道有沒有接好就用 sensor_ok()。EV3 MicroPython v2 的 Ev3devSensor：讀不到會出現 OSError，程式停下來，要插回去再重新執行。在右邊勾「拔掉感應器」可以看到這兩種情形。
    2. 
      
  2. 顏色要在感應器上設定，程式改不了。色相看的是「設定 1：COLOR」的取色點，色塊看的是「設定 2：TRACK」選的顏色，都只能用感應器機身的按鍵設定。沒做設定 1 時色相一直是 0，跟紅色一樣，程式會以為看到紅色。
    3. 
      
  3. 先判斷有沒有找到色塊。沒找到時色塊 X、Y、寬、高、面積都是 0，看起來像「色塊在左下角」。所以先用 found()（或色塊寬 = 0）判斷，再看位置。
    4. 
      
  4. EV3 上幾乎全部都是模式 1。函式庫的 hue() 到 blob_h()、found()、area()、blob_xya()、read_all() 都讀模式 1，一起讀不會變慢；area() 是寬 × 高算出來的。EV3 讀不到 device_id()、firmware_version()（只有 SPIKE 有）。
    5. 
      
  5. 座標方向：站在車後面往前看，X 是左右，正中間約 50，所以 X − 50 在左邊是負數、右邊是正數。Y 是上下：下面小、上面大。左右剛好相反時，到感應器的鏡頭選單切換 H-Mirror。動態值要機器人停住才準。
