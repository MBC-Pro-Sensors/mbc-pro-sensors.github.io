MBC 神攝手 學校版 × micro:bit（MakeCode）

三個步驟用 micro:bit 讀神攝手

在 MakeCode for micro:bit 上，先加入 MBC 擴充，再在「當啟動時」等相機就緒，最後把讀值積木放進「重複無限次」。左邊一步一步做，右邊的積木會跟著長出來；這些積木圖是用 MakeCode 自己的渲染器畫的，跟你在編輯器看到的一樣。右上角可以切到 JavaScript，跟 MakeCode 右上的切換一樣。

MakeCode 免費、免登入，用 Chrome 或 Edge 打開就能寫；程式按「下載」存成 .hex，拖進 micro:bit 就會跑。

1

加入 MBC 擴充、接好線

micro:bit 本來不認得神攝手。加入 MBC 擴充後，積木區會多一個「MBC 感應器」分類，神攝手的積木都在「神攝手」那一組。先選你的 micro:bit 版本，下面的硬體關卡會跟著換。

你的 micro:bit 是哪一版？（背面有寫 V2 的就是 V2）
  1. 打開 MakeCode，按「新專案」。
  2. 積木區最下面點「進階」→「擴充功能」。
  3. 搜尋框貼上 https://github.com/contactmbcrobot/pxt-mbc-sensors，按 Enter，點 mbc-sensors。
  4. 要中文積木：右上齒輪 →「Language」→ 繁體中文。
2

當啟動時：等相機就緒

相機開機要幾秒鐘。程式一開始先等它準備好：有接好就打勾，沒接好就打叉，馬上知道線有沒有接對。

感應器的 I2C 位址
  1. 從「邏輯」拖「如果…那麼…否則」放進「當啟動時」。
  2. 從「MBC 感應器」→「更多」拖「等位址 … 的裝置就緒，最多 … 毫秒」放進條件，位址選 76（0x4C）、填 3000。
  3. 從「基本」拖兩個「顯示 圖示」，一個選打勾、一個選打叉。
  4. 「重複無限次」裡先放「暫停 100 毫秒」。

3

使用讀值積木

「MBC 感應器 → 神攝手」有色塊位置、顏色、動態、事件等積木；「裝置」組是每款 MBC 感應器都有的共用積木。點一個功能，積木和輸出會換成它的範例。

模擬感應器（相機看到的畫面）：拖動色塊，看右邊的輸出怎麼變

模擬畫面是示意：數值換算簡化過，實際相機會因為光線差幾格。十字 = 取色點（相機上「設定 1：COLOR」選的位置），顏色讀的是十字那一點；綠框 = 相機追到的色塊（「設定 2：TRACK」選的顏色）。X 左 0、右 100；Y 下小、上大（最上 75）。

使用注意

    
  1. 拔線不會讓程式停：相機讀不到時，讀值積木回 0（是／否積木回「否」），也不會印任何訊息。所以「色相 = 0」可能是紅色，也可能是沒接好；要分清楚就用「位址 … 的裝置就緒？」。勾下面的「拔掉感應器」試試看：連「當神攝手 色塊 不見」都會觸發。
  2. 先判斷有沒有找到色塊：沒找到時色塊 X、Y、寬、高、面積都是 0，看起來像「色塊在左下角」，所以先用「神攝手 有找到色塊？」判斷再看位置。
  3. 顏色要在相機上設定：顏色（色相、飽和度、明度）看「設定 1：COLOR」的取色點，色塊看「設定 2：TRACK」的顏色，只能用相機機身的按鍵設定。沒做設定 1 時色相一直是 0，跟紅色一樣。
  4. 座標方向：站在車後面往前看，X 左 0、右 100、中間約 50（X − 50：左負右正）；Y 是下面小、上面大（最上 75）。色相 0～100：紅 0（100 也是紅）、黃約 17、綠約 33、青約 50、藍約 67、洋紅約 83；−1 = 黑白灰。
  5. WRO 版的積木（色點 …）在學校版讀不到：顏色碼、鮮豔度讀到 0，「神攝手 色點 … 是 …？」一律回「否」。學校版只用上面這些積木；WRO 版（HUE12）請看它自己的教學頁。
  6. 相機是 ESP32：它不能讓 micro:bit 等它（不能時脈延展），擴充每次寫完編號會自己等 2 毫秒再讀，不用另外加暫停。
