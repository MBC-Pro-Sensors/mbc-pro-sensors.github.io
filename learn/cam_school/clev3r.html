三個步驟用 clev3r 讀神攝手

clev3r（EV3 BASIC）程式照這個順序：先建立專案、選孔位，再設定感應器的模式，最後才讀值、顯示在 EV3 螢幕上。左邊一步一步做，右邊的程式會跟著長出來；在模擬的相機畫面裡拖動色塊、換顏色、調大小，就能看到 EV3 螢幕會顯示什麼。

1

建立專案、選孔位

clev3r 不用裝擴充，也不用匯入檔案：感應器在 EV3 上會模擬成樂高原廠的紅外線感應器（類型 33），直接用 Sensor 指令讀。第一行 folder 決定程式放在 EV3 的哪個資料夾。

  1. 安裝 clev3r（本站測試的版本是 v1.7.1.0）。
  2. EV3 先開機，再把感應器插進下面選的孔。
  3. 新增一個程式，寫下面這幾行。
  4. 寫好按「編譯並下載」，到 EV3 的檔案選單找 MBC_ 開頭的資料夾執行。
感應器插在哪個孔？

程式裡的第 1 個數字（例如 Sensor.SetMode(1, 0)）就是孔位，1~4 對應 EV3 的 1~4 號孔。

2

設定模式

感應器有好幾種「模式」，每種模式一次送回幾個數字。Sensor.SetMode(孔, 模式) 選一種。一個程式只用一種模式：EV3 每換一次模式要等約 0.5 秒。

3

讀值、顯示在螢幕上

Sensor.ReadRawValue(孔, 第幾個) 拿目前模式的第幾個數字（從 0 開始數），LCD.Text 把它寫在 EV3 螢幕上。EV3 螢幕只能顯示英文和數字，所以標籤用英文縮寫。點一個讀值，程式和螢幕會換成它的範例。

模擬感應器（相機看到的畫面）：拖動色塊，看右邊的輸出怎麼變

模擬畫面是示意：數值換算簡化過，實際感應器會因為光線差幾格。十字 = 取色點（感應器上「設定 1：COLOR」選的位置），色相、飽和度、明度讀的是十字那一點；綠框 = 感應器追到的色塊（「設定 2：TRACK」選的顏色）。X 左 0、右 98；Y 下 1、上 75。

使用注意

    
    
      
  1. 一個程式只用一種模式。模式 1 一次給 8 個數字（色相到色塊高），最常用；只看顏色可以用模式 0。EV3 每換一次模式要等約 0.5 秒。
    2. 
      
  2. 拔線時讀到 0。clev3r 的 Sensor.ReadRawValue 拿不到資料時回傳 0，程式不會停；色相 0 會被當成紅色、色塊寬 0 會被當成「沒看到」。要知道有沒有接好，用「感應器有接好嗎」那張卡的 Sensor.GetType。
    3. 
      
  3. 顏色要在感應器上設定。色相看「設定 1：COLOR」的取色點，色塊看「設定 2：TRACK」選的顏色，只能用感應器機身的按鍵設定。沒做設定 1 時色相一直是 0（跟紅色一樣）。
    4. 
      
  4. 先看色塊寬是不是 0。沒找到時 X、Y、寬、高都是 0。面積用寬 × 高自己算。座標：X 左 → 右、正中間約 50；Y 下小、上大。
    5. 
      
  5. clev3r 讀不到的：感應器身分、韌體版本（EV3 沒有送）。EV3 螢幕只能顯示英文和數字，所以 LCD.Text 的標籤用英文縮寫。
