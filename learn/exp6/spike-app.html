樂高官方 SPIKE App：用 Python 控制 EXP6

樂高官方 SPIKE App 的積木只能控制樂高自己的零件，EXP6 不是樂高的裝置，積木裡沒有它，要改用官方 App 的 Python。先把 EXP6 的函式庫裝進主機一次，之後每個 Python 專案寫一行 from MBC_exp6_SPIKE_App_Lib import MBC_EXP6 就能用。

1. 把函式庫裝進主機（只要做一次）

  1. 下載 install_exp6_lib.llsp3（安裝程式）。
  2. 主機用 USB 或藍牙連上樂高官方 SPIKE App，「檔案」→「開啟」→ 選這個檔。
  3. 按 ▶ 執行一次，下方主控台出現「安裝成功！(Installation Successful!)」就完成了。

主機重新安裝或更新韌體之後，函式庫會被清掉，要再執行一次。

2. 直接開範例最快

下面 5 個範例已經寫好，下載後用官方 App 開啟、按 ▶ 就能跑（EXP6 的 Host 線插主機 C 孔、接上 EXP6 的電池）：

  1. 範例 1：一顆馬達轉一圈
  2. 範例 2：三顆馬達一起轉
  3. 範例 3：光控開關（顏色感應器控制馬達）
  4. 範例 4：用主機按鈕控制馬達
  5. 範例 5：兩輪小車走正方形

每個範例的說明、接線和「會看到什麼」在 EXP6 SPIKE 新手範例頁；全部指令的說明在 官方 App 專區。

3. 跟另外兩種寫法不一樣的地方

  • 建立物件寫 MBC_EXP6(port.C)（官方 App 用 port.C，Pybricks 寫數字 3）。
  • 官方 App 沒有自動保護：開頭要等 2 秒讓馬達準備好，程式最後一定要寫 exp6.stop_all(1)，不然馬達會維持最後一個指令。
  • 轉角度只看角度的正負決定方向；反射光是用紅綠藍估算的，數字會跟 Pybricks 差一點；絕對角度是 -180 ～ 179。
  • 換另一種寫法（Pybricks、MBC 積木網站）之前，先讓 EXP6 斷電一次（關主機或拔掉 Host 線）。

官方 App 的 Python 範例是照函式庫寫的，還沒在每一版 App＋主機上逐支跑過；有問題請告訴我們。

想用積木拼？

改用 MBC SPIKE 積木網站（免費、免登入、中文積木，主機要裝 Pybricks 韌體），或 Pybricks 積木。想打字寫程式、用到 EXP6 全部功能：看 Pybricks（MicroPython）教學。
