MBC EXP6 六路馬達擴充器 × 樂高官方 SPIKE App

三個步驟用官方 SPIKE App 的 Python 控制 EXP6

在樂高官方 SPIKE App 寫 Python 一定照這個順序：先匯入函式庫，再建立物件、幫 EXP6 取名字，最後才用這個名字去呼叫功能（轉馬達、讀感應器）。左邊一步一步做，右邊的程式會跟著長出來；在模擬 EXP6 上選每個擴充孔接什麼，就能看到馬達怎麼轉、程式會印出什麼。

你的主機：SPIKE Prime，用官方 App 的教育版（SPIKE 3）。官方 App 的積木只能控制樂高自己的零件，EXP6 要用 Python。EXP6 只能接 SPIKE Prime（不能接 EV3），要接上自己的電池，馬達才會動。
1

匯入函式庫

官方 App 不能像 Pybricks 那樣匯入檔案，所以要先把 EXP6 的函式庫裝進主機一次，之後每個 Python 專案最上面寫三行匯入就能用。沒有匯入，後面寫的 MBC_EXP6 主機看不懂，會出現 ImportError 或 NameError。

  1. 下載 install_exp6_lib.llsp3（安裝程式）。檔名是 MBC_exp6_SPIKE_App_Lib（裝進主機的函式庫名字）。
  2. 主機用 USB 或藍牙連上官方 SPIKE App，「檔案」→「開啟」→ 選這個檔，按 ▶ 執行一次。下方主控台出現「安裝成功！(Installation Successful!)」就裝好了。
  3. 只要裝一次；主機重新安裝或更新韌體之後函式庫會被清掉，要再執行一次。不要了就執行下載包裡的 Uninstall_MBC_exp6_Lib.py。
  4. 新增一個 Python 專案，在最上面寫下面這三行（右邊程式標 ① 的地方）。
2

建立物件：幫 EXP6 取名字

要「建立一個物件」：告訴程式 EXP6 的 Host 線插在主機哪個孔，並幫它取個名字。之後要轉馬達、讀感應器，都是叫這個名字。官方 App 版沒有多工，程式一行一行往下跑，等待用 time.sleep()。

EXP6 的 Host 線插在主機哪個孔？

要不要開啟多工？

程式裡的 port.C 是主機的孔：port.A～port.F（官方 App 寫字母；Pybricks 才寫數字 3）。後面功能括號裡的第一個數字，才是 EXP6 上的擴充孔 1~6，兩個不要搞混。

3

使用功能

寫法都是「exp6.功能名稱(擴充孔, …)」：名字＋小數點＋功能，括號裡第一個數字通常是 EXP6 上的擴充孔 1~6。點一個功能，程式和輸出會換成它的範例，模擬 EXP6 的馬達也會照著動。

模擬 EXP6（從上面看）：選每個擴充孔接什麼，看馬達怎麼轉、右邊印出什麼

一開始孔 1、2 接馬達，孔 4 顏色、孔 5 超音波、孔 6 力量感應器，跟範例程式用的孔一樣。模擬畫面是示意：馬達速度 1% 當成每秒 10 度（實際要看馬達型號），感應器的數值也簡化過；紅色指針是轉軸的朝向，↻ = 順時針。官方 App 版沒有看門狗：程式跑完（或按停止），馬達會維持最後一個指令一直轉，所以程式最後要寫 exp6.stop_all(1)。顏色照官方 App 版函式庫用紅綠藍換算（綠色是 5、看不到顏色是 0，跟 Pybricks 版不一樣）；超音波看不到東西讀到 -1。

    使用注意
    
    
      
      
    1. 一定要接 EXP6 的電池。擴充孔上的馬達全部靠 EXP6 自己的電池（建議 2S 鋰電池），只接 Host 線、不接電池，什麼都不會動。EXP6 的擴充孔可以接樂高馬達、樂高 SPIKE 的顏色、超音波、力量感應器，也可以接 MBC 感應器（見上面「MBC 感應器插在 EXP6」）。
      2. 
      
    2. 兩種孔不要搞混。MBC_EXP6(port.C) 的 port.C 是主機的孔；exp6.motor_run(1, 50) 的 1 是 EXP6 上的擴充孔（板子上印的 1~6）。
      3. 
      
    3. 沒有看門狗，馬達要自己停。程式跑完、當掉或按停止，馬達都會維持最後一個指令。每個程式最後都寫一行 exp6.stop_all(1)。等待用 time.sleep()；keep_alive_wait()、keep_alive() 只是為了讓 Pybricks 版的程式也能跑才保留。
      4. 
      
    4. 轉角度送出就往下做，不會等轉完。motor_run_degrees()、motor_track_target() 後面要等一下，或一直讀角度等它到。剛開機時馬達大約要 1～2 秒才準備好，程式開頭先等 get_device_id(孔) == 5。
      5. 
      
    5. 換另一種寫法之前，先讓 EXP6 斷電一次（關主機或拔掉 Host 線）。EXP6 一旦跑過 Pybricks 程式，就會一直用 Pybricks 的方式溝通，直到重新開機，這時候官方 App 會連不上。
