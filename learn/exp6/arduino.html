三個步驟用 Arduino 控制 EXP6

寫 Arduino 程式照這個順序：先選板子、接好線、貼上通訊小幫手，再在 setup() 用 exp6Begin() 叫醒 EXP6，最後在 loop() 送指令、讀值（轉馬達、讀角度、讀感應器）。EXP6 走 UART 序列埠，不是 I2C。左邊一步一步做，右邊的程式會跟著長出來；在模擬 EXP6 上選每一埠接什麼，就能看到馬達怎麼轉、序列埠監控視窗會印出什麼。

1

選板子、接線，貼上小幫手

Arduino 用 UART 序列埠（TX／RX 兩條線）跟 EXP6 講話，不能用 I2C，也不用安裝函式庫。程式最下面貼一段「通訊小幫手」，之後就能用 exp6Send() 送指令、exp6Receive() 收資料。出貨的 EXP6 不用重燒韌體：收到 Arduino 的第一包指令，就自動從「樂高模式」切到「UART 模式」。

你用哪一塊板子？（只差接哪幾腳，程式完全一樣：小幫手會自己選序列埠）

UNO R3、Nano 只有一組硬體序列埠（D0／D1），已經接著 USB。EXP6 每 0.01 秒回傳一包資料，速度固定 115200 不能改；改用軟體序列埠（SoftwareSerial）在 115200 收不穩，收資料時也不能同時送指令。所以程式在這種板子上會印「這塊板子……不能接 EXP6」然後停下來。請改用 UNO R4、Mega 2560 或 ESP32。

  1. 接線前先拔掉 USB 線和電池。用「樂高 6 針轉杜邦線」（或樂高接頭轉接板）接 EXP6 的 Host 孔（接主機的那個孔）。
  2. Host 孔第 3 腳 GND → GND、第 4 腳 VCC → 5V（第 4 腳也是 EXP6 的「開機鑰匙」，沒電 EXP6 不會開機）
  3. 第 5 腳（EXP6 收）→ D1（TX）、第 6 腳（EXP6 送）→ D0（RX）。兩條線是交叉的；第 1、2 腳不接。
  4. EXP6 的 XT30 電源座一定要接 2～3S 鋰電池，馬達和感應器都靠它供電。EXP6 不會供電給 Arduino：Arduino 用 USB 或行動電源另外供電。
  5. 打開 Arduino IDE：檔案 → 新增，把原本的內容刪掉；開發板選你的板子（例如 Arduino UNO R4 Minima）。
  6. 最下面貼「通訊小幫手」（右邊程式標 ① 的地方，按「複製程式」會一起拿到）。最上面兩行是接線的註解，提醒你哪條線接哪裡。
2

叫醒 EXP6，等它準備好

setup() 是開機時只跑一次的地方：打開序列埠、用 exp6Begin() 叫醒 EXP6（最多等 3 秒，順便讓馬達停下、角度歸零），再等 1.5 秒讓馬達和感應器被認出來。等待一律用 exp6Wait()，不要用 delay()：EXP6 超過 0.5 秒沒收到指令，就會自動把馬達停下來（看門狗）。

使用功能

送指令寫「exp6Send(L1, L2, L3, L4)」，或用範例裡的 motorRun() 這類「指令小抄」函式；讀值先用 exp6Receive() 收一包最新資料，再用 exp6Port(埠)、exp6Device(埠) 讀。點一個功能，程式和序列埠監控視窗會換成它的範例，模擬 EXP6 的馬達也會照著動。

模擬 EXP6（從上面看）：選每一埠接什麼，看馬達怎麼轉、右邊序列埠監控視窗印出什麼

一開始第 1、2 埠接馬達，第 4 埠顏色、第 5 埠超音波、第 6 埠力量感應器，跟功能範例用的埠一樣。模擬畫面是示意：馬達速度 1 當成每秒 10 度（實際要看馬達型號），感應器的數值也簡化過；紅色指針是轉軸的朝向，↻ = 順時針。拔掉 Host 線時 EXP6 會關機（第 4 腳是它的開機鑰匙）、馬達停下，exp6Receive() 收不到資料、回傳 false；exp6Port() 會留著上一包的數字，所以範例都先檢查 exp6Receive()。插回去 EXP6 重新開機，收到 Arduino 的下一包指令就自動切回 UART 模式。只在 setup() 做一次的功能，loop() 空著，大約 0.5 秒後看門狗會讓馬達停下（轉角度還沒轉完的會先轉完）。

使用注意

    
    
      
  1. 一定要接 EXP6 的電池和第 4 腳。馬達和感應器全部靠 EXP6 自己的電池（2～3S 鋰電池）；第 4 腳是 EXP6 的「開機鑰匙」，電壓要跟板子的訊號一樣（UNO R4、Mega 接 5V，ESP32 接 3V3）。EXP6 的埠只認得樂高馬達和樂高 SPIKE 的顏色、超音波、力量感應器。
    2. 
      
  2. 等待用 exp6Wait()，不要用 delay()。EXP6 超過 0.5 秒沒收到 Arduino 的任何指令，就會自動把馬達停下來（看門狗）。motorRun(1, 50); delay(3000); 只會轉 0.5 秒；motorRun(1, 50); exp6Wait(3000); 才會轉 3 秒。算很久的地方中間送 exp6Send(1, 0, 0, 0)。
    3. 
      
  3. 拔線不會讓程式停。收不到資料時 exp6Receive() 回傳 false（範例印「收不到資料，檢查一下線有沒有鬆掉。」），exp6Port()、exp6Device() 還是上一包的數字，所以每次讀值前先檢查 exp6Receive()。在右邊勾「拔掉 EXP6 的 Host 線」可以看到這個情形。開機時找不到 EXP6，exp6Begin() 回傳 false。
    4. 
      
  4. 指令的 L1～L4 都要在 0～100。連續送兩筆一模一樣的指令，第二筆會被略過（轉角度、角度歸零不受這條限制）。轉角度的指令只送一次，EXP6 會自己轉到位；轉到之後再收到同一筆，它會再轉一次。
    5. 
      
  5. 剛插上的裝置要 1～2 秒才會被認出來（exp6Device() 會先是 0）。UNO R3、Nano 不能用：唯一的硬體序列埠被 USB 用掉了。UNO R4 上傳程式時不用拔掉 D0、D1 的線。序列埠監控視窗的速度選 115200。
