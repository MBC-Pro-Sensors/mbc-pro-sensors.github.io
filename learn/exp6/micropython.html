MBC EXP6 六路馬達擴充器 × Pybricks

三個步驟用 MicroPython 控制 EXP6

寫 Pybricks 程式一定照這個順序：先匯入函式庫，再建立物件、幫 EXP6 取名字，最後才用這個名字去呼叫功能（轉馬達、讀感應器）。左邊一步一步做，右邊的程式會跟著長出來；在模擬 EXP6 上選每個擴充孔接什麼，就能看到馬達怎麼轉、程式會印出什麼。

你的主機：SPIKE Prime（EXP6 只能接 SPIKE Prime，不能接 EV3）。EXP6 要接上自己的電池，馬達才會動。
1

匯入函式庫

程式的第一件事是告訴 Pybricks「我要用 EXP6 的函式庫」。沒有這行，後面寫的 MBC_EXP6 主機看不懂，會出現 NameError。EXP6 只有這一個函式庫，不用選。

  1. 下載函式庫（存成檔案，檔名不要改）：MBC_exp6_obj_Lib.py；檔名是 MBC_exp6_obj_Lib.py。
  2. 在 Pybricks Code 左邊檔案區按「Import a file」，把它匯入同一個專案。
  3. 檔名不要改（程式裡寫的就是 MBC_exp6_obj_Lib），也不要放進子資料夾。
  4. 回到主程式，在最上面寫下面這幾行（右邊程式標 ① 的地方）。
2

建立物件：幫 EXP6 取名字

要「建立一個物件」：告訴程式 EXP6 的 Host 線插在主機哪個孔，並幫它取個名字。之後要轉馬達、讀感應器，都是叫這個名字。

EXP6 的 Host 線插在主機哪個孔？

要不要開啟多工？

程式裡的 3 是主機的孔：1~6 = A~F（只能寫數字，不能寫成 Port.C）。後面功能括號裡的第一個數字，才是 EXP6 上的擴充孔 1~6，兩個不要搞混。

3

使用功能

寫法都是「exp6.功能名稱(擴充孔, …)」：名字＋小數點＋功能，括號裡第一個數字通常是 EXP6 上的擴充孔 1~6。點一個功能，程式和輸出會換成它的範例，模擬 EXP6 的馬達也會照著動。

模擬 EXP6（從上面看）：選每個擴充孔接什麼，看馬達怎麼轉、右邊印出什麼

一開始孔 1、2 接馬達，孔 4 顏色、孔 5 超音波、孔 6 力量感應器，跟範例程式用的孔一樣。模擬畫面是示意：馬達速度 1% 當成每秒 10 度（實際要看馬達型號），感應器的數值也簡化過；紅色指針是轉軸的朝向，↻ = 順時針。拔掉擴充板時馬達會停，讀到的值都變成 0（不是上一次的值）。程式跑完後大約 0.5 秒，EXP6 的看門狗會讓馬達停下（轉角度還沒轉完的會先轉完）；開多工並用函式庫的 run_task 時，程式一結束馬達就停。

使用注意

    
    
      
  1. 一定要接 EXP6 的電池。擴充孔上的馬達全部靠 EXP6 自己的電池（建議 2S 鋰電池），只接 Host 線、不接電池，什麼都不會動。EXP6 只能接樂高馬達和樂高 SPIKE 的顏色、超音波、力量感應器；MBC 的感應器請直接插主機。
    2. 
      
  2. 兩種孔號不要搞混。MBC_EXP6(3) 的 3 是主機的孔（1~6 = A~F）；exp6.motor_run(1, 50) 的 1 是 EXP6 上的擴充孔（板子上印的 1~6）。
    3. 
      
  3. 等待用 keep_alive_wait()，不要用 wait()。EXP6 超過 0.5 秒沒收到主機的訊號，會讓馬達自己停下來（看門狗，保護用，關不掉）。一般寫法的等待一律寫 exp6.keep_alive_wait(毫秒)；算很久的地方中間補一次 exp6.keep_alive()。開多工時用函式庫的 run_task()，背景會自動送，直接 await wait() 就好。
    4. 
      
  4. 拔掉擴充板不會讓程式停。讀到的值會變成 0（不是上一次的值），動作送不出去，電腦畫面每秒最多印一行提醒；插回去會自己重新連線。要知道有沒有接好就看 exp6.connected。在模擬 EXP6 勾「拔掉擴充板」可以看到這個情形。
    5. 
      
  5. 轉角度送出就往下做，不會等轉完。motor_run_degrees()、motor_track_target() 後面要等一下，或一直讀角度等它到；還沒轉完又送一個轉角度，第二個會被丟掉。剛開機時馬達大約要 1 秒才準備好，程式開頭先等 get_device_id(孔) == 5。程式最後寫一行 stop_all(1) 讓馬達全部停下。
