三個步驟用 Pybricks 積木讀測距者 8 路

積木跟 MicroPython 一樣照這個順序：先在「set up」下面匯入函式庫，再建立物件、幫感應器取名字，最後在「program」下面用這個名字呼叫功能。左邊一步一步做，右邊的積木會跟著長出來；這些積木圖是直接從 Pybricks Code 拼好匯出的，跟你在畫面上看到的一樣。

先確認：Pybricks 的積木模式要授權碼或 Patreon 贊助才能用。沒有授權可以改寫 MicroPython，寫法一模一樣（右邊切到「對應的 MicroPython」就看得到）。

1

匯入函式庫

積木程式的第一件事，是在黃色「set up」下面接一塊紅色的「from … import …」積木，告訴 Pybricks 要用測距者 8 路的函式庫。

選一種函式庫（兩種積木完全一樣，只差 from 後面的名字）：

  1. 下載函式庫（存成檔案，檔名不要改）：MBC_laser8.py（只接測距者 8 路）或 MBC_sensors.py（統一函式庫）；你選的是 MBC_laser8.py。
  2. 在 Pybricks Code 左邊檔案區按「Import a file」，把它匯入同一個專案，檔名不要改。
  3. 按「+」新增檔案，選用積木（blocks）寫。
  4. 從積木清單拖出紅色的「from … import …」，接在「set up」下面，選好兩個名字。
2

建立物件：幫感應器取名字

再拖一塊紅色的「… is a …」積木接在匯入積木下面：最左邊是你幫感應器取的名字，後面是孔位和要不要多工。之後每次讀值，都是選這個名字。

使用注意

    
    
      
  1. 函式庫檔要先匯入專案。沒有匯入 MBC_laser8.py，紅色積木裡選不到 MBC_LASER8。
    2. 
      
  2. await 和 call 要跟多工一致：多工 true 就選 await，多工 false 就選 call。混著用，程式會在主機上出錯。
    3. 
      
  3. 積木背後就是 MicroPython。Pybricks Code 右邊的程式窗格就是積木產生的程式，跟這頁「對應的 MicroPython」一樣（多工版會多一行 await wait(0)，是 Pybricks 自動加的）。
    4. 
      
  4. 拔線不會讓程式停：讀不到時回傳上一次讀到的值；用 sensor_ok 功能可以知道有沒有接好。讀到 120 可能是沒東西、超過 120 公分、剛開機（等 2～4 秒）或那一路故障，要分辨故障用 is_ok。is_ok、init_status、fault_status、read_all、device_id、firmware_version 只有 SPIKE 有；毫米那一組（nearest_mm、front_mm、nearest_dir）要感應器韌體 2026-10 以後。
    5. 
      
  5. 方向：站在車後面往前看，左邊是負數、右邊是正數；第 1 路朝正左邊、第 4、5 路朝正前方、第 8 路朝正右邊。最近的方向 −7 ~ +7，±8 = 四周沒有東西，所以判斷有沒有東西用 min_distance 大於等於 120。
