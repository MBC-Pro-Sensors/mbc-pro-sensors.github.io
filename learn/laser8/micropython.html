三個步驟用 MicroPython 讀測距者 8 路

寫 Pybricks 程式一定照這個順序：先匯入函式庫，再建立物件、幫感應器取名字，最後才用這個名字去呼叫功能。左邊一步一步做，右邊的程式會跟著長出來；拖動模擬感應器下面的障礙物方向和距離，就能看到程式會印出什麼。

你的主機：
1

匯入函式庫

程式的第一件事是告訴 Pybricks「我要用測距者 8 路的函式庫」。沒有這行，後面寫的 MBC_LASER8 主機看不懂，會出現 NameError。

選一種函式庫（兩種寫法完全一樣，只差 import 那一行）：

  1. 下載函式庫（存成檔案，檔名不要改）：MBC_laser8.py（只接測距者 8 路）或 MBC_sensors.py（統一函式庫）；你選的是 MBC_laser8.py。
  2. 在 Pybricks Code 左邊檔案區按「Import a file」，把它匯入同一個專案。
  3. 檔名不要改，也不要放進子資料夾。
  4. 回到主程式，在最上面寫下面這幾行（右邊程式標 ① 的地方）。
2

建立物件：幫感應器取名字

一台車可能接好幾個感應器，所以要「建立一個物件」：告訴程式感應器接在哪個孔，並幫它取個名字。之後每次要讀值，都是叫這個名字。

使用注意

    
    
      
  1. 拔線不會讓程式停。讀不到時回傳上一次讀到的值，從來沒讀到過就回傳 None，電腦畫面印一行提醒；插回去自動恢復。要知道有沒有接好就用 sensor_ok()。在右邊勾「拔掉感應器」可以看到這個情形。避障時拔線，車子會照最後的距離繼續開，要小心。
    2. 
      
  2. 讀到 120 有 4 種可能：那個方向真的沒東西、東西超過 120 公分、剛開機還沒準備好（開機後要等 2～4 秒）、那一路故障。要分辨故障用 is_ok()。黑色、亮面、透明的東西比較難量，判斷距離建議設在 60 公分以內。
    3. 
      
  3. 方向：站在車後面往前看，左邊是負數、右邊是正數；第 1 路朝正左邊、第 4、5 路都朝正前方、第 8 路朝正右邊。有東西時方向是 −7 ~ +7（−7 正左、−5 左前 60°、−3 左前 30°、−1～+1 正前方）；±8 = 四周沒有東西（停在上次看到的那一側，開機是 −8）。所以判斷「有沒有東西」用 min_distance() >= 120，判斷「在正前方」用 abs(方向) <= 1。
    4. 
      
  4. 同一個迴圈盡量用同一組：SPIKE 是 distances()、ch()、min_direction()、min_distance()、max_direction()、max_distance()、is_ok()、init_status()、fault_status()、read_all() 一組（最常用）；nearest_mm()、front_mm()、nearest_dir() 一組；device_id()、firmware_version() 放在迴圈外面。換一組感應器要多花幾十毫秒。EV3 是 distances()、ch() 一組；min_direction()、min_distance()、max_direction()、max_distance() 一組；nearest_mm()、nearest_dir() 一組；front_mm() 單獨一組，換一組要約 0.5 秒。
    5. 
      
  5. 毫米功能要新韌體：nearest_mm()、front_mm()、nearest_dir()、device_id()、firmware_version() 要感應器韌體 2026-10 以後的版本，舊韌體讀到的會是別的數字。距離本身每 0.1 秒左右才更新一次，迴圈 wait(20) ~ wait(50) 就夠了。
