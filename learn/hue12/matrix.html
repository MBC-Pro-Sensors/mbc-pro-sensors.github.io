MBC 神攝手 WRO 版（HUE12） × MATRIX Mini R4（MATRIXblock）

三個步驟用 MATRIXblock 讀神攝手 WRO 版（HUE12）

在 MATRIX Mini R4 的 MATRIXblock 軟體裡，神攝手 WRO 版（HUE12）會被當成一台 mVision 攝影機（串口），用內建的 mVision 積木就能讀，不用裝函式庫：先在「Mini初始化」的設置裡放MVision 初始化，再在循環裡放MVision 輪詢，最後把MVision 數值積木放進「有數據」那一格。左邊一步一步做，右邊的積木會跟著長出來；這些積木圖是用 MATRIXblock 自己的積木程式畫的，跟你在軟體裡看到的一樣。

MATRIXblock 是 MATRIX 原廠的免費積木軟體（預設裝在 C:\matrixblock-r4\）。感應器要買 MATRIX 版，接 Mini R4 給 mVision 攝影機用的串口。

1

初始化：打開 mVision

神攝手 WRO 版（HUE12）在 MATRIX 上被當成一台 mVision 攝影機，走串口，不是 I2C。程式的第一件事，是在藍色「Mini初始化」積木的「設置」裡放「MVision 初始化」。

接線：感應器接 Mini R4 給 mVision 攝影機用的串口（Serial1，115200），不用選孔。

  1. 打開 MATRIXblock。新專案的工作區已經有一顆藍色的「Mini初始化」積木（沒有的話到「Mini Core」類別拖一顆）。
  2. 左邊積木類別點「偵測」，找到「MVision 初始化」。
  3. 把它放進「設置」。
2

在循環裡放「MVision 輪詢」

「MVision 輪詢，有數據」積木會等感應器送來新的一包資料，收到就跑上面那一格，等不到（約 0.5 秒）就跑「無數據」那一格，所以循環裡不用另外放等待。

  1. 從「偵測」拖「MVision 輪詢，有數據／無數據」放進「循環」。
  2. 在「無數據」裡放「USB序列埠輸出 沒有收到資料 並換行」（在「序列埠」類別），拔線時就看得出來。

「Mini初始化」上的「序列埠:On」「Baud:9600」不要改：範例用「USB序列埠輸出…並換行」把數值印在資訊窗口（資訊窗口的鮑率也選 9600）。

3

使用 MVision 數值積木

「偵測」裡的「MVision 0 數值」積木，下拉選單選第幾格資料，每一格是神攝手 WRO 版（HUE12）的一個值。範例放在「有數據」那一格裡面。點一個功能，積木和輸出會換成它的範例。

使用注意

    
    
      
  1. 接線：神攝手 WRO 版（HUE12）接 Mini R4 給 mVision 攝影機用的串口（Serial1，115200），不是 I2C 孔；程式只用「MVision」積木，不要用顏色感應器積木。
    2. 
      
  2. 照 WRO 範例解碼：WRO 版的資料排法沒有改，跟 WRO 2026 隊伍在用的 HUE12_AS_mVisionSensor_v1.0.8.mbr4 範例一樣（顏色碼用「除以 256 的餘數」和「/ 256 向下取整」，鮮豔度用 /1、/16、/256、/4096 再除以 16 的餘數）。
    3. 
      
  3. 只用資料 0 ～ 8：WRO 版每包 9 格（資料 0 ～ 8），資料 9 一直是 0；下拉選單的「10」不要用。
    4. 
      
  4. 小數點：「除以…的餘數」和「向下取整」算出來是小數，印出來會帶 .00（例如 80.00），拿去比較大小完全沒問題。
    5. 
      
  5. 拔線時：「MVision 輪詢」等不到資料（約 0.5 秒）就跑「無數據」那一格，資料停在上一次收到的值。
