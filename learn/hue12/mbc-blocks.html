三個步驟用 MBC 積木網站讀神攝手 WRO 版

在 MBC SPIKE 圖控編程網站 上，神攝手 WRO 版不用匯入函式庫：先在「開機時執行一次」裡告訴網站感應器接哪個埠，再放主迴圈，最後把讀值積木放進主迴圈。左邊一步一步做，右邊的積木會跟著長出來；這些積木圖是直接從網站拼好匯出的，跟你在網站上看到的一樣。

網站免費、免登入；主機要裝 Pybricks 韌體（網站「SPIKE 主機」選單可以幫你燒）。

1

設定：哪個埠接神攝手

程式的第一件事，是在黃色「開機時執行一次」下面接一塊「○ 埠 接 MBC 神攝手HUE12」，網站才知道那個埠接的是神攝手 WRO 版。

感應器接在哪個埠？
  1. 打開 MBC SPIKE 圖控編程網站，按「+」開一個新程式。
  2. 左邊積木類別點「MBC 感應器」→「神攝手HUE12」，第一顆就是「○ 埠 接 MBC 神攝手HUE12」。
  3. 把它接在「開機時執行一次」下面，下拉選單選 C。
2

放主迴圈

讀感應器要一直重複讀，所以要有黃色的「主迴圈（一直重複）」。裡面先放一顆「等待 100 毫秒」，讓它每 0.1 秒讀一次，不會讀太快。

  1. 從「控制」拖出「主迴圈（一直重複）」，放在設定積木下面空白的地方（不用接在一起）。
  2. 再拖一顆「等待 100 毫秒」放進主迴圈。

網站產生的程式會自動放進多工架構（async），不用自己選，也不用寫 await。

3

使用讀值積木

「MBC 感應器 → 神攝手HUE12」裡面還有 6 顆讀值積木，每顆中間都有埠的下拉選單，要選跟第 1 步一樣的埠（C）；有「第 N 格」的積木，後面那格填第幾格（1 ~ 12）。網站每次用到讀值積木都會自己讀感應器，不用另外放「讀一次」的積木。點一個功能，積木和輸出會換成它的範例。

使用注意

    
    
      
  1. 設定積木只要一顆。同一個埠只能設定一次；讀值積木的埠要跟設定積木一樣，選錯埠網站會在下載前提醒。
    2. 
      
  2. 不用下載函式庫，也不用「讀一次」。網站下載程式時會自動把神攝手的讀值程式一起傳到主機；每顆讀值積木自己會讀感應器（10 毫秒內重複讀，用的是同一筆資料，一次讀 12 格也不會變慢）。
    3. 
      
  3. 跟 Pybricks 函式庫一樣：MBC_hue12.py 有的功能這裡都有積木（get_slot() ＝「第 N 格（名稱, 色相, 飽和度）」，只要名稱用「第 N 格顏色名稱」；sensor_ok() ＝「感應器有接好」），讀到的值也一樣；函式庫的 update() 網站不需要。拔線不會讓程式停：讀不到時回傳上一次的值，終端機印一次提醒；用「感應器有接好」可以知道有沒有接好，插回去自動恢復。在右邊勾「拔掉感應器」可以看到這個情形。
    4. 
      
  4. 沒有身分資料：這款感應器沒有送身分和韌體版本，所以也沒有這兩顆積木。
    5. 
      
  5. 色相怎麼看：0～239 是彩色（紅色在頭尾：0～9 和 230～239，判斷紅色要寫「色相 < 10 或 色相 ≥ 230 且 < 240」）、240～245 白、246～250 黑、255 = 這一格沒設定（感應器還在選單裡時，12 格也全部是 255）。「第 N 格有顏色」就是色相不是 255，所以白、黑也算「是」。顏色名稱：Red 紅、Org 橘、Yel 黃、Lim 黃綠、Grn 綠、Mnt 薄荷綠、Cyn 青、Azr 天藍、Blu 藍、Prp 紫、Mag 洋紅、Pnk 粉紅、Wht 白、Blk 黑、NONE 沒設定。
