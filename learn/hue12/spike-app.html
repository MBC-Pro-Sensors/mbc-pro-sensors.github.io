樂高官方 SPIKE App：用 Python 讀神攝手 WRO 版

樂高官方 SPIKE App 的積木只認得樂高自己的感應器。神攝手 WRO 版不是顏色感應器（它的裝置代號是 95），所以積木讀不到它，要改用官方 App 的 Python。官方 App 的 Python 讀得到每一格的色相和飽和度，下面三步就能開始。

1. 新增 Python 專案

打開樂高官方 SPIKE App → 新增專案 → 選「Python」（不是 Word Blocks）。

2. 直接開範例最快

下面 5 個範例已經寫好「讀神攝手的小工具」，下載後用官方 App 開啟，照著改就好：

  1. 範例 1：讀第 1 格的色相
  2. 範例 2：第 1 格是不是紅色
  3. 範例 3：12 格裡有幾格看到顏色
  4. 範例 4：依顏色轉向
  5. 範例 5：看物塊顏色，決定從哪邊繞過

每個範例的說明、接線和「會看到什麼」在 神攝手 WRO 版 SPIKE 範例頁。

3. 讀到的值

感應器把畫面分成一排 12 格。每一格有色相（0～255，255＝這格沒有顏色；240～245 白、246～250 黑）和飽和度。12 格的位置要先在感應器上設定好，做法在範例頁的「開始之前」。

官方 App 的 Python 範例目前只做過語法檢查，還沒在每一版 App＋主機上逐支跑過；有問題請告訴我們。

想用積木或顏色名稱？

想用積木拼：改用 MBC SPIKE 積木網站（免費、免登入，主機要裝 Pybricks 韌體）。想直接拿到「紅、藍、綠」這種顏色名稱：用 Pybricks（MicroPython） 或 Pybricks 積木 加 MBC 函式庫。
