MBC 掌控者 PS2／PS4 × Pybricks 積木

三個步驟用 Pybricks 積木讀掌控者遙控接收器

積木跟 MicroPython 一樣照這個順序：先在「set up」下面匯入函式庫，再建立物件、幫接收器取名字，最後在「program」下面用這個名字呼叫功能。左邊一步一步做，右邊的積木會跟著長出來；這些積木圖是直接從 Pybricks Code 拼好匯出的，跟你在畫面上看到的一樣。

先確認：Pybricks 的積木模式要授權碼或 Patreon 贊助才能用。沒有授權可以改寫 MicroPython，寫法一模一樣（右邊切到「對應的 MicroPython」就看得到）。

1

匯入函式庫

積木程式的第一件事，是在黃色「set up」下面接一塊紅色的「from … import …」積木，告訴 Pybricks 要用掌控者的函式庫。

選一種函式庫（兩種積木完全一樣，只差 from 後面的名字）：

  1. 下載函式庫（存成檔案，檔名不要改）：MBC_gamepad.py（只接掌控者）或 MBC_sensors.py（統一函式庫）；你選的是 MBC_gamepad.py。
  2. 在 Pybricks Code 左邊檔案區按「Import a file」，把它匯入同一個專案，檔名不要改。
  3. 按「+」新增檔案，選用積木（blocks）寫。
  4. 從積木清單拖出紅色的「from … import …」，接在「set up」下面，選好兩個名字。
2

建立物件：幫接收器取名字

再拖一塊紅色的「… is a …」積木接在匯入積木下面：最左邊是你幫接收器取的名字，後面是孔位和要不要多工。之後每次讀按鍵或搖桿，都是選這個名字。

3

使用功能

在「program」下面放紅色的功能積木：第一格選名字 pad，中間選 await，最後一格選功能。要讀按鍵或搖桿，迴圈裡第一塊先放「pad … update」（可以上下疊的那種功能積木），讀一次手把，後面的積木才會拿到新的值。按鍵、搖桿的名稱填在功能積木右邊多出來的那一格（按「>」打開），例如 CROSS、LY，要用大寫。點一個功能，積木和輸出會換成它的範例。

模擬手把：點按鍵、拖動搖桿，看右邊的輸出怎麼變

模擬畫面是示意：點一下按鍵＝按住，再點一下放開；拖動搖桿的圓點改變位置（放開滑鼠會停在那裡，按「全部放開」回到中間）。搖桿 1 ～ 9、5 = 中間，往右、往上數字變大。PS4 手把的電量固定示意為 80。

使用注意

    
    
      
  1. 函式庫檔要先匯入專案。沒有匯入 MBC_gamepad.py，紅色積木裡選不到 MBC_GAMEPAD。
    2. 
      
  2. await 和 call 要跟多工一致：多工 true 就選 await，多工 false 就選 call。混著用，程式會在主機上出錯。
    3. 
      
  3. 每一圈先放 update。buttons、pressed、any_pressed、stick、stick_centered、buttons_psx、pressed_psx 讀的都是上一次 update 拍下的快照；少了 update，數值會一直停在第一次讀到的樣子。connected、battery、kind、device_id、firmware_version 不用 update。
    4. 
      
  4. 積木背後就是 MicroPython。Pybricks Code 右邊的程式窗格就是積木產生的程式，跟這頁「對應的 MicroPython」一樣（多工版會多一行 await wait(0)，是 Pybricks 自動加的）。
    5. 
      
  5. 拔線不會讓程式停：讀不到時回傳上一次讀到的值；用 sensor_ok 功能可以知道有沒有接好。搖桿往右、往上數字變大（1 ～ 9，5 = 中間）；當開關時用 7 以上、3 以下，左右兩邊才會一樣靈敏。PS4 的 SHARE = SELECT、OPTIONS = START。
