不匯入函式庫，用 Pybricks 內建積木讀掌控者

掌控者插在 SPIKE 上會被當成樂高顏色感應器，所以 Pybricks 內建的顏色感應器積木就讀得到：reflection()（反射光）和 ambient()（環境光）兩個數字，掌控者在裡面各裝了一組值，用數學積木拆開就能用。左邊一步一步做，右邊的積木會跟著長出來；積木圖是直接從 Pybricks Code 拼好匯出的。

跟「Pybricks 積木（匯入函式庫）」差在哪？
  • 這頁：不用下載、匯入任何檔案，打開 Pybricks 就能拼；但PS2 只拿得到 11 個按鍵和搖桿、PS4 只拿得到搖桿，要自己用 // 和 % 拆。
  • 匯入函式庫：要先匯入 MBC_gamepad.py，但PS2、PS4 都讀得到全部 16 個鍵、搖桿、手把有沒有連上、電量，一個功能一個積木。

先確認：Pybricks 的積木模式要授權碼或 Patreon 贊助才能用。沒有授權可以直接寫 MicroPython，寫法一模一樣（右邊切到「對應的 MicroPython」）。

1

set up：建立顏色感應器、選孔

不用匯入函式庫：在黃色「set up」下面接 Pybricks 內建的顏色感應器積木（ColorSensor），選掌控者插的孔，名字取 pad。

  1. 在 Pybricks Code 按「+」新增檔案，選用積木（blocks）寫。
  2. 從「Sensors（感應器）」拖出顏色感應器的設定積木（感應器圖示），接在「set up」下面，名字改成 pad（可以取任何英文名字），孔選上面那個。
2

program：讀 reflection() 和 ambient()

在「program」下面放「repeat while true」，裡面用「print」印出 pad reflected light（reflection）和 pad ambient light（ambient），最後「wait 100 ms」。Pybricks 讀 reflection 時會自動把感應器切到 SPIKE 模式 5、讀 ambient 時切到模式 7，掌控者在這兩個模式各放一組數字：

reflection() 是整數（0～2047），不會變負數；ambient() 是小數，4 個搖桿方向各佔一位數（小數點前 LX、LY，小數兩位 RX、RY）。

3

用數學積木拆開、使用

先用「Variables」的「set to」把讀到的值存進變數：r＝reflection，a＝ambient ×100 再四捨五入（round）。再用「Math」的 //（÷ 取整數）和 %（÷ 的餘數）拆成兩個值，印出來或拿來判斷。點一個功能，積木和輸出會換成它的範例。虛線框的是另一款接收器用的（點下去會幫你換）。

模擬手把：點按鍵、拖動搖桿，看右邊的輸出怎麼變

模擬畫面是示意：點一下按鍵＝按住，再點一下放開；拖動搖桿的圓點改變位置（放開滑鼠會停在那裡，按「全部放開」回到中間）。搖桿 1 ～ 9、5 = 中間，往右、往上數字變大。PS4 手把的電量固定示意為 80。

使用注意

    
    
      
  1. 只有 2 個數字。reflection() 和 ambient() 各一個，其他值讀不到（第 2 步表格下面有列）。要用請改 匯入函式庫的 Pybricks 積木。
    2. 
      
  2. ambient() 先 ×100 再 round：小數直接拆會有誤差（例如 70.03 × 100 可能是 7002.9999），四捨五入成整數再用 // 和 %。
    3. 
      
  3. PS4 接收器只有搖桿：數值對照表沒有登記 PS4 的模式 5，這頁不教 PS4 用 reflection()；PS4 的按鍵也不在 ambient() 裡。PS4 要讀按鍵請改用 匯入函式庫的 Pybricks 積木。
    4. 
      
  4. 手把沒連線：按鍵全放開（0）、搖桿在中間（55.55），內建積木分不出「沒連線」和「沒按」。
    5. 
      
  5. 搖桿只有 1～9：不是 −100～100，要自己減 5 再乘 25。
    6. 
      
  6. 不要用「color」積木或顏色名稱比對。掌控者放的是數字，一律存進變數用數字比大小。拔掉感應器時內建積木會出錯讓程式停下（函式庫版不會）。
    7. 
      
  7. 積木背後就是 MicroPython。Pybricks Code 右邊的程式窗格就是積木產生的程式，跟這頁「對應的 MicroPython」一樣。
